          新增完整分数匹配和 AT/EOS 决策指标：完整拍位要求该事件所有 P 数字都预测正确；“该续写时选择续写”和“该结束时选择结束”单独统计，避免高格式准确率掩盖早停。这些都基于给定正确前缀的训练预测，不是自由生成的采音正确率；启用续写与结束学习权重后，总损失另含该辅助项，不能直接与旧损失比较。

          等级、Radar 和 Style 分别控制什么？
        
              
          先理解后调整：后端把这些值作为 GenerationCondition 的软条件发送给模型，取值范围都是 0–1。
          Radar / 复杂度描述“谱面有多少、哪里爆发、使用什么节奏动作”；Style / 表现倾向描述“这些动作在全曲中偏向怎样组合”。
          note_density 是整体 notes/sec 目标，peak 是局部爆发密度；sweep、slide_tricky、slide_sequence 与
          slide_bias 共同表达 Slide 运动倾向；chord 与 chord_bias 共同表达和弦倾向；
          jack 表达同键连打，hold_bias 表达 Hold，touch_bias 表达 Touch，directionality 表达环形轨道上的移动方向感。
          这些值不是官方机台雷达公式，也不是硬约束；当前模型可能弱化或忽略部分 Style 条件，生成后应查看质量报告。
        
              
          
              等级标签来自原谱的 &lv_x。精确小数按原值读取；13+ 会按项目规则映射为 13.7，无法恢复官方精确定数。
            单改等级不会自动改变 Radar / Style；这里的等级基准会同时同步它们。当前仍没有官方定数评分器。
              
        
              

              
          高级微调 · Radar / Style 参数

                CURVE
                谱面强度曲线
                
          拖动曲线点只改变强度，不改变时间位置
        
                
        
                这里编辑局部谱面强度意图。0.5 对应生成页的全曲密度基准，低于它请求减弱，高于它请求加强。人工修改只改变强度目标；基础密度与类型通道保留模型预测，并随新增控制点按时间插值。可用下方时间段标记显式休止区；休止区独立于曲线值，即使 strength 为 0 也会生效。已开始的 Hold / Slide 可以跨入休止区。
                
        
                
          尚未选择歌曲
          
          
        
                
        
        
                
          
          
          
          
          
        
                
        
                「增强强弱对比」基于当前整首曲线，每次将相对 0.5 的差值放大 1.25 倍：0.3 → 0.25，0.7 → 0.75，0.5 不变，结果限制在 0–1。
          不改变时间位置，原有零值休止保持为零；无论是否框选或缩放，都会作用于全曲。可以连续点击或撤销；完成后点击「保存并返回生成页」。
          此操作扩大目标落差，不保证平均难度不变；若生成响应不明显，请检查指导强度与 follow / hard / soft 的跟随幅度限制。

                上手指南
                1. 直接写谱：切到顶部「生成谱面」，导入歌曲音频和 .pt 模型文件，选一个一键写谱预设，点底部「生成谱面」。
                2. 在线试玩与打分：生成后展开页面顶部的「谱面预览」即可在线播放；满意的片段可收进示范库，反哺下次训练。
                3. 清洗素材再训练：自己准备训练集时，先去「训练素材」运行自动体检并试听待复核片段，再去「训练模型」选好显卡预设开训。
                4. 随时放心微调：自动体检绝不改动原始谱面文件；时间轴标注优先用于选中的片段，整谱学习决定在素材目录修改。
