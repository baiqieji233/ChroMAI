G. 金标集（高质量谱面）用你认可的好谱面当训练组和验收标准

        

          为什么要这一步？只训练、不验收，你无法判断模型是"学会了"还是"背下了"。
          金标集就是你自己挑的一批好谱面，程序会把它们切成三份：
          预训练集（原训练集，但剔除金标验证曲）、金标微调集（第二阶段精调用）、
          金标验证集（永不训练，只用来打分）。
          之后训练时「验证 manifest」指向金标验证集，模型选择就自动偏向"像好谱面"；生成时「金标统计」填上，就能拿到逐项 PASS/FAIL 的验收报告。
        


        

          
最简单：把好谱面放进一个 gold 文件夹

          
在训练集目录下新建 gold 文件夹，每首金标曲放成独立文件夹，格式和训练集里的歌完全一样：

          
训练集目录\
├─ 某首歌\            ← 普通训练数据（本来就是这样的）
│    maidata.txt
│    track.mp3
└─ gold\              ← 新建这个文件夹，把好谱面放进来
    ├─ GoodChart1\
    │    maidata.txt
    │    track.mp3
    └─ GoodChart2\
         maidata.txt
         track.mp3

          

            要点：① 每首歌一个文件夹；② 文件夹里必须有 maidata.txt；
            ③ 音频必须是 track.mp3 / track.wav / track.ogg 这三个名字之一；
            ④ 可以嵌套多层（如 gold/2024精选/GoodChart1/）；⑤ 放多少首都行，建议验证集至少 30 首。
            这些金标曲可以是新歌（不在原训练集里），程序会自动纳入。

C. 目标条件以下都是软条件，用来引导模型，不保证结果

        

          等级、Radar 和 Style 分别控制什么？
        

          先理解后调整：后端把这些值作为 GenerationCondition 的软条件发送给模型，取值范围都是 0–1。
          Radar / 复杂度描述“谱面有多少、哪里爆发、使用什么节奏动作”；Style / 表现倾向描述“这些动作在全曲中偏向怎样组合”。
          note_density 是整体 notes/sec 目标，peak 是局部爆发密度；sweep、slide_tricky、slide_sequence 与
          slide_bias 共同表达 Slide 运动倾向；chord 与 chord_bias 共同表达和弦倾向；
          jack 表达同键连打，hold_bias 表达 Hold，touch_bias 表达 Touch，directionality 表达环形轨道上的移动方向感。
          这些值不是官方机台雷达公式，也不是硬约束；当前模型可能弱化或忽略部分 Style 条件，生成后应查看质量报告。
        

          
等级标签来自原谱的 &lv_x。精确小数按原值读取；13+ 会按项目规则映射为 13.7，无法恢复官方精确定数。
            单改等级不会自动改变 Radar / Style；这里的等级基准会同时同步它们。当前仍没有官方定数评分器。

        

        

          
1 · 选择目标等级自动配好对应的密度与常规写法，每 0.1 档都有基准。

          

            
            
12.0 · 较轻15.0 · 较重

          

          
填好数字或拖动后会自动应用等级基准，并保留下面勾选的偏好。也可输入 13.45 等数值，由相邻 0.1 档插值。
            修改等级或偏好会重新计算 Radar / Style，覆盖高级微调；不会改采样、曲线或音频边界。若在使用模型来源曲线，改完后请重新生成曲线。

          
2 · 加上特殊偏好可多选；不选就是该等级的常规写法。

          

            
            
            
            
            
            
            
          

          
明显 · 50%

          
0 恢复常规基准；力度越高，越向同等级真实谱面中的相应倾向靠拢。多选会平衡各项偏好，不会机械相加；相反偏好可能互相减弱。
            改变配置种类仍可能影响实际难度，即使密度不变。等级与偏好都是软条件，最终请试玩。

Style / 表现倾向

            

          

        

        

        

          
          
        

        

          关于条件遮罩：这是训练阶段的 condition_mask_prob，决定训练样本有多少次使用 null/default 条件；它不表示生成页的滑条“永远有效”或“0.5 就是不设定”。
          生成页会把你当前填写的 Radar / Style 原样放入后端条件文件，实际影响大小仍取决于 checkpoint 是否学会使用这些条件。
          默认值来自 full 训练集的中位数；目标等级语料范围为 12.0–15.0，低于 12 属于明显的训练分布外请求。
        


        
D. 采样与随机性控制“同一个模型能产出多少种结果”
          
        

        
改动这些参数后若想回到出厂设置，点右上角「恢复生成默认值」即可；它不会影响训练参数。

        

          调整顺序：先选等级预设并点击「应用组合」，保持随机采样开启、Temperature 0.65、Top-p 0.9、条件强度 guidance scale 1。
          全曲太密或太空，先改「整体密度」与「峰值密度」；配置种类不合适，再改 Radar / Style；只有局部段落不合适时，编辑强度曲线。
          想比较效果，固定随机种子，每次只改一组参数。温度控制随机性，最大事件 tokens 控制解码预算，它们都不是难度旋钮。
        

        

          曲线如何变成生成目标：曲线值 0.5 表示你设定的全曲密度基准，低于 0.5 请求减弱，高于 0.5 请求加强；模型来源的原始曲线估计的是相对谱面负荷。
          它不直接指定某种 Slide / Touch，也不把曲线值换算成官方定数。只有「启用谱面张力曲线」已勾选、当前歌曲曲线已保存、指导强度大于 0 时，人工曲线才参与生成。
          
默认参数示例：soft、指导强度 0.65、跟随幅度 0.5 时，曲线 0.2 / 0.5 / 0.8 对应约 0.675 / 1 / 1.325 倍的密度目标。
          这是目标倍率，实际音符数仍由模型决定；soft 不会在生成后按倍率删音符。
        

        

          

            
            
            0.50
            

              
              
              
            

            仅适用于已检查且训练了 music_structure_v3 fine_rhythm 的 checkpoint。0 偏主音，0.5 跟随每窗口预测，1 偏细碎音型；这是柔性调制，不会锁定三连音、附点或某种节奏类别。可与局部曲线和键盘/星星等配置偏好叠加：曲线控制局部负荷，偏好影响配置类别。
          

          

            
            
            0.00
            检查当前生成 checkpoint 后确认能力。
            0 关闭；可先试温和的 0.3–0.6，增强局部音乐节拍对落点的指导。不会强制每个音乐峰都加音符或指定三连音；它不替代强度曲线或密度限制。旧模型及未训练此辅助头的 checkpoint 不支持。
