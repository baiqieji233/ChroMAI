# 当前架构兼容版发布说明

日期：2026-10-12。发布标签：`legacy-compatible-2026-10-12`。此标签固定当前架构，作为后续重构前可以下载、继续使用和回退的基线。

## 无需重新训练即可使用

- MiaCode 无理检测已移植为项目内的 Python 实现，保留现有 WebUI、CLI、检测类别、阈值、修复与复检接口，不需要 DLL、Qt 或独立 MiaCode 进程。
- 保留跨窗口冲突归因、前置 Hold/Slide 修复、少量 note 编辑、窗口重试及回溯功能；使用现有界面选择策略。
- 生成侧不再重复扣减前置上下文 token 预算，原 checkpoint 的窗口布局和总容量仍优先使用。
- 多候选排序纳入检测完整性及参与处理的剩余硬无理；设置为仅报告的类别不按强制处理类别处罚。
- 等级、Radar、Style 改动后可以继续使用已经保存的强度曲线，并显示提醒；音频、checkpoint 身份、BPM、first 和 tempo map 的不匹配仍按原规则校验。
- 保留前后端参数同步、有效设置与修复日志，以及验证集可选的既有工作流。

兼容表示已有模型能够通过对应生成路径继续使用，不承诺更新前后相同随机种子产生逐字相同的谱面；预算、候选排序和检测修正可能改变最终输出。

## 已有模型的配置边界

本次发布打包完整当前工程，保留已有训练与研究功能，但不将以下功能宣称为旧模型自动获得的能力：

| 内容 | 已有模型直接生成时 | 要获得新能力时 |
|---|---|---|
| 持续动作摘要 | 原 checkpoint 未包含时关闭 | 明确启用并加强训练 |
| 音频池化策略 | 继承 checkpoint 保存的策略 | 加强训练可迁移到逐样本池化 |
| 上下文预算上限 | 继承 checkpoint 的数值 | 加强训练可在原总容量内调整 |
| 新训练的谱面过滤与预算策略 | 不重写现有模型的数据合同 | 新训练或加强训练时使用并记录 |
| 双手模拟、神经改稿等后续架构 | 尚未实现，不参与生成 | 属于后续重构规划 |

当前事件模型按自己的数据合同加载；旧固定帧模型仍走单独的兼容生成路径，不能当作事件 checkpoint 加载。本次只读检查的 Prism_v3 为 epoch 15，25,719,557 参数，持续动作摘要关闭，旧池化策略，前置上下文 512 tokens、总预算 1024。

## 使用方式

1. 获取此标签对应的源码。发布源码包和 GitHub 标签源码快照都保留 `START_WEBUI.bat`。
2. 将代码放在独立目录，双击 `START_WEBUI.bat`，按 [Windows 一键启动说明](WINDOWS_QUICKSTART.md) 配置运行环境。
3. 导入已有 checkpoint 和目标音频，按原生成流程操作。源码包不附带训练权重。
4. 如果是在原工作区更新代码，重启 WebUI 服务并刷新浏览器，使前后端加载同一版本。

本次没有启动正式训练，没有转换或覆盖 checkpoint，也没有开始下一代架构改造。
