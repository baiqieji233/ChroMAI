## 已完成修改与实现流程

### 1. 生成保护回到有明确意义的控制

删除未提交版本中加入的局部键位集合去重与字符级时值惩罚；同时删除以连续 Touch 次数、双押/单键严格交替次数为依据的额外压制。用户请求的 Style 比例、局部多押比例、已有 Break/多押反馈、物理/参考检查仍保留。正常局部交互、连 Touch、时值相同不再单凭重复次数被逼着改变。

恢复等距节奏流的豁免，不因超过 48 个间隔就惩罚；原有可关闭的复合节奏循环控制保持不变。没有加入“Slide 必须对称”“终点等于另一条起点就禁止”等规则，没有修改游戏判定或以响度切谱。

这些变动对重新启动的生成进程和旧权重可立即生效，但并不追溯消除权重已经学到的复读倾向。

### 2. v14 训练合同、旧权重生成与迁移

训练语义升级为 `chart_stream_training_v14_causal_motor_masks`，checkpoint 增加 `training_objective_contract=causal_motor_objectives_v1`。严格 resume 同时检查语义、目标版本和数据指纹。

`StreamConfig.motor_profile` 默认 `legacy_v13`，用于缺少此字段的旧权重；fresh/finetune 的 CLI 自动解析为 `causal_hands_v1`，resume 从新 checkpoint 继承。数据指纹包含该特征版本，原始确定性音频/时钟缓存身份保持不变。

旧权重仍可按其 legacy 输入生成。新 24 维击键双手特征使用独立 `hand_projection`，新分支零初始化；迁移时不扩张原 65 维投影，也不随机改变已有音频/解码器权重。新配置声明双手特征但缺失相应权重时直接拒绝，不能静默零填充假装能力存在。

finetune 改用新特征时，将改变含义的运动学第 23 列投影清零：legacy 是连续 buttonless 事件衰减，新版本是“已知无按钮头事件”标志；未知遮罩仍是 0。禁止 finetune 静默移除已训练的双手分支。

额外循环退出 CE 恢复与主 CE 共用有效 token 分母：权重 0.25 表示标记 token 附加 25% 的主 CE 梯度，不随标记稀疏程度提高至附加 100%。保留原谱真实时值/Touch/局部键位集合退出标签，未生成错误前缀监督，也未惩罚真实延续。

### 3. 一次决定、按明确事件所有者应用间隔遮罩

`masked_clock_inputs` 可返回已选中的 interval 事件集合，不额外重复抽随机数。数据侧将 prefix 和 history 的局部索引转换成全曲事件索引。

在新特征下，查询处于 `<note>` 之后、`<end>` 之前时：当前公开间隔属于 `committed`，最近已完成间隔属于 `committed-1`；事件边界则公开的是 `committed-1` 的间隔。这个区别决定时钟 15:17、运动学当前 age16/历史 interval17 以及新双手 age 字段的遮罩。还覆盖了计算块开头从 history 继承的间隔，防止只遮住 history 本身而漏掉 decoder 的首个查询。

绝对拍位、秒数、BPM、已提交动作和原谱目标仍保留。这是显式间隔回声通道的一致遮罩，不承诺无法从所有已知位置重新计算时间差，也不是删除正常音乐上下文。

### 4. 多假设双手击键历史

`stream/hand_tracking.py` 为单个事件保留至多 8 个潜在双手分配，考虑位置、实际时间、移动连续性和 Hold 持续占用；同时保留连续使用同一手与换手的可能性，不把某个事件奇偶或某条固定手法当作标签。

24 维特征包含两条潜在击键轨迹的位置、位移、距上次击键的时间、已知状态、Hold 剩余时间、连续使用长度，以及候选不确定性、重复/换手的软权重、在途 Slide 归属未知等。候选权重是启发式归一化证据，**不是经过校准的真实分手概率**。Touch 不伪造按钮落点，被遮罩的未知事件会清除分配证据。对长 Slide，未知归属仍按全部已提交动作的实际时间保留，不用固定 32 事件截断。

训练按歌曲/镜像缓存稀疏前缀检查点，遇到遮罩从遮罩之前的检查点重放；未遮罩未来事件不参与当前特征。推理使用同一实现，增量追加；资源轮换时仍可按 committed 索引查询同一段历史。新特征经投影进入 action 分支，影响解码器与候选概率；没有另加一个强迫交替的手顺惩罚器。

内存方面，训练不为每个事件保存完整分配历史：每 128 事件保存稀疏检查点、不保留额外近期快照；推理每 32 事件保存检查点并保留最多 64 个近期状态。单事件分配数固定上限，避免搜索指数增长。小规模 CPU 测量：1500 事件、160 查询含遮罩，首次约 90 ms，热查询约 15.4 ms；这不是完整训练吞吐测量。

### 5. 保守间隔引导

原 plan 标签/维度和 SmoothL1 主目标不扩张，新增独立统计：`interval_mae_beats`、`interval_log_mae`、`interval_targets`、负值预测数。训练误差可能乐观，不能当验证集置信度。

生成对缺少足够残差统计的旧权重使用 0.25 辅助倍率；新统计可将倍率调整至最高 0.75，误差越大越弱。普通 log-ratio 间隔评分先封顶至 0.5，再乘用户强度与该倍率；接近零的预测额外衰减。负值等无效预测保持不提供间隔引导。模型仍可输出任意符合用户分母/时间约束的 Fraction。

“非预期长空白抑制强度”保持独立，未借减弱普通间隔项悄悄关闭用户已有的大跳保护；它仍可能在 plan 判断错误时压低真实休止，用户可单独设 0。输出报告保存原始 interval 预测及实际辅助倍率，避免将原始负值在 clipped 字段中误读为可信的零间隔。
