## 实施内容

`src/maichart/composer/train.py` 将模型输出、总 loss、反向 loss 的有限数检查合成一次检查。正常情况下，每个设备只读取一次检查结论；异常情况下仍读取具体失败项。未参与 loss 的输出也会检查，梯度和更新后参数检查保留。运行日志标识为 `packed_outputs_and_losses_v1`。

正式运行将微批从 64 改为 128，梯度累积从 4 改为 2，有效批量保持 256。模型结构、特征版本、目标函数、留出集、恢复采样、学习率及原余弦退火终点保持原设置。未开启 torch.compile，也未默认增加采样线程；之前实际测试中，双采样线程比单线程慢。

微批变化不是逐位等价恢复：加权损失归约、动态填充和 dropout 会改变数值轨迹。本次使用显式 `rebatch_resume`，恢复优化器、随机状态和样本游标，并沿用原采样器的微批顺序，避免因为批号改变而跳错训练位置。保存点对应已消费 512000 个样本，新逻辑跳过 4000 个 128 样本批次。
