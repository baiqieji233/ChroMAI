# 主界面新建 Composer 训练：参数与分组

本轮只调整主工作台的训练设置、参数传递和说明，不改变训练算法。独立Composer页面已弃用。

## 第一次新建训练怎么填

1. 选择训练素材，模型族选 `chart_composer_v1`，训练方式选“从头训练（fresh）”。
2. 输出目录填写一个没有旧检查点的新目录，例如 `checkpoints/prism_composer_v22`。fresh不需要填写已有模型路径。
3. 在“设置训练与输出”中填下面的常用值。也可先点“应用重训默认值”，再手动选择稳定配置协同。
4. 保留“验证与生成对照”，让每轮同时检查未参与训练的歌曲和实际生成。高级设置通常保持默认。
5. 检查摘要后启动。首次启动可能准备音频和结构缓存；不要把准备时间当成每轮GPU计算时间。

| 主界面术语 | 新建训练起始设置 | 作用 |
|---|---|---|
| 训练 epochs | 20 | 训练目标轮数，不能保证第20轮一定优于之前的检查点。 |
| 学习率 lr | 0.0002 | 每次更新的步长；本表用于fresh，已有模型微调另定。 |
| batch size | 64 | 每个小批次的样本数，影响显存。显存不足先降到32。 |
| 梯度累积 | 4 | 64×4约为每次更新256样本；降到32时可用累积8保持乘积。 |
| 设备 | 自动或CUDA | 使用可用显卡；CPU不适合全量长训。 |
| 配置质量架构 | 稳定配置协同：采音分档、类别守恒与动作支持检查 | 新版协同结构；需要新训练阶段。选“自动”目前不会自动启用它。 |
| 数值精度 | 自动 | 本机可用时使用BF16。 |
| 结构分析后端 | 自动 | 按实际环境选择；新环境缺少Beat This时应核对日志中的实际后端。 |
| 学习率变化方式 | 自动 | 当前fresh自动为恒定；要用余弦，手动选余弦，预热与末尾比例可留空自动选择。 |
| 独立验证集清单 | 留空 | 自动按歌曲组划分。已有独立验证清单时填写其路径。 |
| 自动留出比例 | 0.05 | 约5%的歌曲组分到开发/最终留出；不是随机抽每张谱的音符。0关闭自动划分。 |
| 每轮验证批次上限 | 32 | 0验证全部；增加会延长验证。 |
| 验证批大小 | 8 | 只影响验证显存与速度；显存紧张可用4。 |
| 每轮闭环生成抽检曲数 | 2 | 保留小规模闭环观察；0关闭生成评估。实际需有可用留出歌曲和相应结构条件。 |
| 闭环生成抽检间隔（轮） | 1 | 每轮进行一次；按需增大以节省时间。 |
| 固定生成随机种子 | 0,1 | 每首固定歌曲使用两个种子，便于发现结果波动。使用英文逗号。 |

页面中生成评估的标签以实际显示为准，其字段分别为 `generation_eval_songs` 和 `generation_eval_interval_epochs`。生成评估会增加每轮末尾耗时；检查误差和实际谱面时也要看任务日志中的评估阶段。

## 参数现在分在哪里

常用方案、验证与生成对照直接显示，不再要求先展开全局的模型架构高级区域。原控件ID保留，浏览器保存的值继续有效。

高级设置默认折叠，内部按用途分为：

| 分组 | 包含内容与使用场景 |
|---|---|
| 模型与输入结构 | 宽度384、6层、8头、前馈1536、历史128、候选96、动作槽位下限8；以及历史几何、独立计时、持续状态、动机与结构策略。改变主干需要新训练；不要凭显存剩余随意加宽。 |
| 正则化与历史稳定 | 普通dropout0.1、条件遮挡0、历史分支0.3、历史模态0.15、台账0.5、结构0.15；历史RMS上限8、残差上限1等。多个“遮挡”作用不同，不要一起随意调大。 |
| 损失与自产历史恢复 | 音频辅助0.15、占用0.15、规划0.2、恢复0.1；恢复间隔25更新、2样本、每次追加2事件；恢复温度1/0.85。通常保留默认，改权重会改变总loss的数值口径。 |
| 性能与缓存 | 准备线程4、样本线程1、CPU算子线程2、预取2、局部性4、音频缓存4GB、缓存路径和优化器实现。按实际吞吐与内存调整，线程越多不一定越快。 |
| 学习率与训练状态 | 余弦预热与末尾比例、训练种子、轮中重分batch。预热和末尾比例留空表示自动；轮中重分batch仅用于resume。 |
| 保存与短程诊断 | 每500更新保存、历史归档、推理权重导出、日志25批、CUDA计时、每轮批数上限、谱面上限。正式训练的批数/谱面上限都保持0。 |

“历史检查点归档”是本轮新增控件：自动在新阶段采用几何间隔保存推理快照；“关闭”只关闭归档，不关闭正常的last检查点保存。归档点不含优化器，resume用完整的 `composer_last.pt`。

折叠菜单只改变显示。里面当前填写的参数仍然会提交，可用页面搜索查找，或用“展开高级设置”一并展开。不要以为收起后参数就失效。

## 本轮补齐的入口

此前训练CLI已有，但主界面没有完整入口的参数：独立验证集、自动留出比例、验证批次上限、验证批大小、固定生成种子、历史检查点归档。现在均接通主界面→API→真实训练命令，支持0与留空的各自含义。

旧模型继承、模型尺寸锁定、恢复温度控制等原逻辑继续使用。训练代码内部的固定系数（例如稳定策略的动作支持下限、辅助梯度缩放）不是现有CLI参数，本轮没有制造只能改显示但不生效的滑块。生成侧的三个协同强度仍放在生成页。

修改后需要重启WebUI后端并刷新主工作台，以加载新增的API传参。已经运行的训练不会因界面重组而改变。
