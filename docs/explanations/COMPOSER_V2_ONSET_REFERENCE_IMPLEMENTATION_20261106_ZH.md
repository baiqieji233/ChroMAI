# 拍内起音参考：本轮实现与使用边界

日期：2026-11-06。

**已完成实验功能接入及兼容性检查；尚未完成完整谱面的质量验收。** 新功能默认不自动开启，原 v6 检查点保留。

## 为什么这样改

上一轮在《Strange Bar》的四处位置验证了：现有声学缓存已经能分辨正确起音，但生成前文把其他落点的概率推得很高。直接按声学峰写音符又会损伤留白，并选出不合适的细碎分音。

这次保留原模型对节奏、休止和配置的判断，补充一条只读音乐的轻量路径。模型已经决定下一个事件属于哪个整数拍之后，新路径比较这一拍内各个候选附近的音乐，为它们提供附加分数。它不把整段锁成16分或24分，也不要求“有声音就一定写音符”。

## 已实现的内容

- 使用已有100 Hz频谱缓存，不重新提取MERT。相同整数拍内的所有候选共享一次卷积计算，新增 **26,048个参数**。
- 数据接口只读取音频、节拍时钟、整数拍和已有词表。读取未来音频符合离线写谱条件，不读取未来谱面答案。
- 声学分数只在输入到达 `[PHASE]` 时作用于 `F:...` 时间符号。重新分配拍内相对概率的同时，保持这些符号原有的总概率质量；同一前文下，其他符号分数保持不变。
- 标准的下一组件交叉熵同时训练旧模型和新路径。本轮没有叠加额外损失、硬性跟峰、分音家族锁定或补音规则。
- 新路径输出零初始化；音频归一化统计仅从训练集读取，并随检查点保存。微调已有声学检查点或继续训练时保留这些统计。
- 原 v6 可以在新目录通过 `finetune` 启用。严格 `resume` 继承原合同，不允许借续训静默更换结构。新旧词表扩展逻辑保留。
- 训练和生成控件均放在原主界面，CLI、API、检查点能力及生成报告已经接通。旧后端不会静默忽略新参数。

“不直接改动休止／配置分数”是同一个前文下的计算保证。落点改变后，后续前文也会改变，因此整谱物量、配置和休止仍需生成验收，不能把局部保证扩大成整谱保证。

## 在主界面如何使用

训练：**训练模型 → 模型与上下文 → 独立起音参考（实验）**。

| 选项 | 行为 |
| --- | --- |
| 自动：继承检查点，新建关闭 | 旧 v6 继续原路径；已有声学检查点继续其原配置。 |
| 关闭 | 保留原选时结构。 |
| 启用拍内声学读出 | 从旧 v6 使用加强训练／finetune，在新目录训练新增路径。 |

生成：检查支持此能力的检查点后，**Composer v2 生成 → 起音参考强度**才出现。

| 数值 | 含义 |
| --- | --- |
| 0 | 关闭附加声学分数。微调过的旧主干权重仍是微调后的版本。 |
| 1 | 使用训练时的强度。 |
| 大于1、最多2 | 实验性加强起音参照，不保证更准确。 |

CLI：训练 `--onset-readout phase_audio_v1`；生成 `--onset-strength 1`。首次尝试建议使用1，不用放大系数替代训练。生成报告中的 `onset_readout` 记录策略、实际强度和作用范围。

目前正在运行的旧训练任务不会在运行中自动升级。应在当前任务结束后重启所用WebUI后台，再使用新目录微调；不要覆盖原 v6。

## 验证结果

1. 修改完成后的相关回归：**190项Python测试、16项JS界面测试通过**。随后补充BF16守恒检查，并复查声学路径及API，**31项专项通过**，其中30项与前一轮重叠。
2. 测试覆盖零初始化、关闭后输出一致、仅作用于时间符号、概率质量守恒、训练梯度、变BPM、非常规分数、未来谱面隔离、不同长度补齐、逐步生成与训练前向对齐。
3. 实际读取 v6 的44,200步检查点，CPU各完成两次普通微调与声学微调更新。声学点保存、重载并继续到第三次更新，归一化统计保持一致，新路径权重确实更新。
4. 使用这份CPU流程检查点，在《Strange Bar》的真实生成前文上重放0／1／2三档强度：参数实际改变了拍内分数，非拍内符号分数逐值一致，拍内总质量一致。
5. 这次CPU短跑只有三次更新，原来的错误落点仍然占优。它验证了功能接线，**没有证明24分问题已经修好**。

原计划进行两组160步GPU短训。执行时发现用户在本轮开始后新启动了 `chart_composer_v2_v6_finetuned` 训练，出现GPU资源争用。因此立即结束了本轮自己的对照进程，保留用户训练；这段运行不用于性能或质量结论。没有继续启动整谱生成对照。

CPU两次更新的训练计算时间约6.55秒与6.49秒，样本过少、运行环境共享，不能据此宣布GPU没有退化。GPU实际吞吐及完整谱面效果仍待空闲时验证。

## 尚待验证的关键问题

- 新路径能否在生成前文已经偏向16分时，恢复真实24分入口，同时保持16分／24分混用。
- 原模型面对真实前文往往已经很自信；仅联合交叉熵能否给声学分支足够的学习机会，尚需短训确认。本轮没有用未经验证的辅助损失强行放大它。
- 该分支只调整已选整数拍内的位置，不能恢复已经被跳过的整个整数拍，也不能单独决定某个声音是否值得采。
- 声学参考是否间接造成连续密度升高、正常休止减少或配置衔接变化，必须看成谱；不能只看loss和候选分数。
- 后续对照应保持父检查点、数据、更新数和生成参数一致，同时比较新检查点的强度0／1，分清额外训练与声学路径的作用。

下一步优先补完已中断的短训和固定歌曲对照，再决定是否扩大训练或改变默认值。当前不建议仅凭本轮流程检查点替换正常生成模型。
