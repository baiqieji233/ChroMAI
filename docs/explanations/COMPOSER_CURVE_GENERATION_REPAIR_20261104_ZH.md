# 11月4日：生成物量暴涨与自动曲线修复

后续更新：配置恢复、Touch类型、Hold时值目标和曲线身份循环问题已继续修复，见[配置恢复修复说明](COMPOSER_CONFIGURATION_RECOVERY_REPAIR_20261104_ZH.md)。本文保留当时的诊断结果；旧v50权重没有被覆盖，新训练目标需要新阶段学习。

本轮检查的是主界面任务`c2369a4b909c`：160.74秒歌曲，使用v50第13轮、7592步，生成2471个出音时刻。原谱、原曲线和原检查点均保留，正式训练原本已由用户停止，本轮未重启。

## 找到的根因

**上轮改了训练目标，却没有把曲线读取接口同步改完整。** 新版最终出音率由音乐、选时和草稿共同决定，旧计划头的第2路只是其中一个特征；另两路不再接受原来的计数／休止监督。自动曲线却继续把它们当作可靠的“每秒音符数”和“休止概率”。这是实现遗漏，不能解释成模型正确预测了很低的物量。

还存在一条明确的放大链：

1. 原生成载入的是v48旧自动曲线，而不是当前v50曲线。
2. 主界面“保存并返回”无条件写入`edited=true`。用户没拖动任何点，也会被当成人工修改，从而绕过自动预览的恒等处理。
3. 自动补全后的生成条件与保存曲线条件不同，旧代码因此清空参考曲线，重新解释整条曲线。
4. 它拿未受监督的计划通道作为新基准，又把旧曲线恢复成绝对物量。最终将事件率均值从2.933放大到12.279次／秒，峰值从6.444放大到39.787。

这条链足以解释密集配置、休止被冲掉和额外分音大量出现。参考依据是原生成报告中`curve.active=true`、`reference_rebased=true`及上述放大数值。

参数中另有总温度1024，但本次候选拍位温度0.65、动作采样温度0.8都显式给定，实际代码使用的是专用温度。没有发现温度与token数串线，也没有用修改温度解释或处理这次问题。

## 已经修改什么

- 保存曲线仅保存现状，真实拖点、休止或多押编辑才保留编辑身份。旧文件如果与参考点完全相同、无休止和多押改动，会恢复为自动预览。
- 新版生成不再读取未受监督的计划通道建立物量基准。用户的曲线改动相对其保存的参考曲线生效，换条件时不会突然变成一条新的绝对物量命令。
- 未改曲线保持严格恒等。实际改动仍进入唯一的最终出音分布，出音、等待和落点一起重算。没有禁用六分／十二分，也没有强制补音或新增重复惩罚。
- 不再拿虚构的头数率建立hard／strict模式的逐段物量配额；实际休止编辑仍生效。
- 更换检查点，或同一路径检查点的epoch／step更新，会停用旧自动预览并提示重算。真正的人工相对编辑保留；异步返回的旧分析结果不能覆盖新检查点。
- 增加一个独立的两维物量预览小头，预测头数率和事件率。复用现有音频及计数标签，按约两秒的实际秒数聚合监督，不建第二套编码器。输入与梯度裁剪都与主模型隔离，辅助误差不会改变主模型梯度或最终出音概率。
- 新头记录实际成功更新次数。v50没有训练这个头，因此当前自动曲线明确显示“音频参考”，不冒充模型物量预测；未修改参考不会反向压制或放大生成。

主要代码：`stream_generate.py`、`stream_curve.py`、`stream_curve_preview.py`、模型／训练／检查点接线、主WebUI及其API。

## 真实验证与边界

使用原音频、种子1、原专用温度和原曲线文件重新生成了一份完整谱。训练已经停止，当前最新点是第14轮8000步；原结果读取的是训练尚在进行时的7592步，因此这不是严格的同权重对照。

| 项目 | 原生成 | 修复后验证 |
| --- | --- | --- |
| 出音时刻数 | 2471 | 712 |
| 曲线是否错误施压 | 是 | 否，倍率最小／最大／均值均为1 |
| 三连音落点比例 | 约16.1% | 约3.23% |
| 是否到达音频末尾 | 是 | 是 |

这些结果证明错误放大已被移除，**不能据此宣布整张谱质量已合格**。修复后的产物位于`.scratch/curve_repair_20261104/corrected/`，真实自动参考位于同目录上一级的`automatic_curve_fixed.json`。

曲线之外，仍有需要继续处理的模型质量问题：

- v50验证总损失在第5轮约6.145，第13轮升到7.319；配置损失从4.402升到5.545，而训练损失仍下降。存在明显的训练／验证分离，最新点不能自动当作最好点。
- 修复后谱面有911个音符原子，其中Touch／TouchHold共236个，约25.9%，高于实际自动条件的约10.95%。首次提议中Touch族已经偏多，不能归咎于守卫重采。E区仍占Touch的约52%。
- 有一根真实46拍、约14.53秒的Hold，配置呼应指标仍为0。这些没有被曲线修复一并解决，不能靠禁长Hold或强迫复制来掩盖。
- 截至8000步，609个恢复监督目标只有68个监督可信配置（约11.17%），541个只监督时间。当前恢复主要练了选时和退出，面对不同自生成前文的配置衔接覆盖仍不足。后续应扩大可认证的接续样本，而不是把不对应前文硬贴回唯一官谱答案。

当前可以优先审看已保留的`composer_best_inference.pt`（第5轮、2920步）；它的开发集表现更好，但本轮没有生成该点，不能承诺其实际手感必然更好。

## 主界面使用

刷新主界面后重新生成自动曲线。对于现有v50，会看到音频参考提示；未改动时直接保存即可，不再触发物量放大。本次生成修复不要求重训主模型。

若之后希望得到模型学习出的物量预览，可在新目录选择“已有模型加强训练”，高级“整曲风格训练”中的“自动曲线预览学习”保持自动，“曲线预览学习权重”保持0.05。它会增加预览头，保留已有主模型权重。旧点直接续训仍继承关闭，不会悄悄启用一个未训练头。本轮没有启动正式加强训练或fresh训练。
