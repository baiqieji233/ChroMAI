# 成对音乐参考、入口读取与衔接示范

这轮保留连续事件生成。目标是让模型更容易判断“过去这段写法哪些适合沿用、眼前音乐哪里发生了变化”，并改善下一事件入口与配置衔接的学习条件。

## 无需重训即可使用的修复

- “节奏与配置一起选”在采音仍随机、配置温度为0时，也会保留多个候选；不再因为配置贪心而关闭节奏比较。
- 普通生成不再导出大量内部试写片段。开启“记录候选评估数据”后，JSONL保存候选事件增量、共同前文身份、真实BPM时间轴和比较范围；记录不会被下一池覆盖。
- 新阶段在限制验证批数时，先均衡覆盖不同音频，再分散抽取其切片。0仍表示完整开发集。训练面板显示实际覆盖、曲线误差和反向传播总目标。
- 重复选入的精选官谱继续按原来的重复次数训练，不自动去重。

## 新音乐上下文怎样启用

在主界面「训练模型 → Composer v2 → 常用训练设置」：

| 控件 | 使用方式 |
|---|---|
| 音乐上下文 | 保持“自动”，或选择“成对音乐参考与前方采音（最新）” |
| 训练方式 | 旧连续事件模型选择 finetune，并填写新输出目录；fresh也可直接使用 |
| 音频编码层数 | 微调时保留父模型层数；这项能力不要求扩层 |
| 节拍结构与对齐参考 | 通常保持自动，使用已有逐拍参考 |

严格 resume 继续父检查点的输入方案，不能用它给旧模型加装新能力。原检查点直接生成时行为仍由原结构决定。新目录微调后的检查点会自动使用新音乐输入，生成页会显示对应状态，无需另调一个强度滑块。

内部版本为 `song_paired_v2`，包含两个小投影：

1. **成对音乐参考**：读取已经找到的参考段与当前段的语义和起音差异。保留已有逐拍可信度、参考丢弃和真实前文保护，模型可以学习沿用、变化或不采用参考。
2. **前方采音读取**：在写下一个整数拍时，额外读取前方0–1、1–2、2–4、4–8、8–16拍的音乐摘要。只提供证据，不规定每个声学峰都要落音，也不限制正常休止的长度。

两项复用已有音乐特征，不再运行MERT，不新增Transformer。宽度512时增加98,816个参数，约为当前58.88M模型的0.17%。来源与当前的音乐证据按拍缓存，入口摘要按音频tile投影一次；不会对每个候选重跑音乐主干。投影从0开始，迁移时保留父模型已学到的输出，再通过微调学习新信息。

这些是改善学习条件的结构变化，实际采音与配置收益仍需用训练后的完整谱面确认。

## 如何训练“从这段前文接下去”

在整谱预览的审阅工具中展开「收集训练示范」：

1. 带前后文试听，圈选你确认值得学习的一段。需要修正时，可以先用MiaCode修改完整谱面，再重新载入该版本。
2. 选择只学采音、只学配置，或两者都学。
3. 如果你也确认了这一段第一步与前文的衔接，选择采音或两者都学后，勾选「同时学习如何接入前文」。
4. 收为示范，再加入下次训练来源；与原训练素材一起在新目录微调。

普通片段只学习被确认的范围；确认接入后，还会学习从实际前文到这段第一个事件的选时。它不会给后续每个切分片段额外制造一个“入口”，也不会把其余未确认内容变成正确答案。只学配置时，首个音符的配置监督本来就保留，入口勾选只用于补充采音的跨界监督。

该功能不会自动修谱，也不把自动选优结果直接作为优秀示范。输入仍是实际前文，目标是人工确认后的续写，避免把原官谱强接到不相容的错误前文上。

## 本轮保留的边界

没有加入左右手强制标注、固定段落模板、最低密度、有声必须落音或通用重复惩罚。正常16分与24分混用、主动舍音、休止及合理重复继续由模型学习。逐键持续占用的新特征暂未加入；其训练、候选时刻与回退状态需要单独设计，不能只在一个路径中增加字段。
