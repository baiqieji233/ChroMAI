# ChroMAI · 成对音乐参考、入口读取与衔接示范

在 **ChroMAI（Composer v2）** 的连续事件生成中，成对音乐参考与前方采音机制用于帮助模型判断“过去这段写法哪些适合沿用、眼前音乐哪里发生了变化”，并改善下一事件入口与配置衔接的学习条件。

## 配套行为与抽样说明

- “节奏与配置一起比较”在采音仍随机、配置温度为 0 时，也会保留多个候选，不会因为配置贪心而关闭节奏比较。
- 常规生成默认不导出内部试写片段；仅当在「高级生成设置」勾选「记录候选评估数据」时，才会写入包含候选增量、共同前文身份、BPM 时间轴和比较范围的 JSONL 记录。
- 训练阶段在限制验证批数时，会先均衡覆盖不同音频，再分散抽取切片；设为 `0` 表示评估完整开发集。训练面板同时显示实际覆盖范围、曲线误差与反向传播总目标。
- 在多来源清单中重复选入的精选谱面会保留其出现次数参与训练，不会自动去重。

## 如何在训练中启用

在主界面「训练模型 → 常用训练设置」中：

| 控件 | 使用方式 |
| --- | --- |
| 音乐上下文 | 保持“自动”，或选择“成对音乐参考与前方采音（最新）” |
| 训练方式 | 旧连续事件模型选择 `finetune` 并填写新输出目录；`fresh` 也可直接使用 |
| 音频编码层数 | 微调时保留父模型层数，该能力不要求额外扩层 |
| 节拍结构与对齐参考 | 通常保持自动，使用逐拍对齐参考 |

严格 `resume` 会沿用父检查点的输入结构，不能直接为旧模型加装新分支；旧检查点直接生成时仍按原结构工作。在**新输出目录**微调后的检查点会自动启用新音乐输入，无需在生成页额外调节强度滑块。

该能力在内部对应 `song_paired_v2` 策略，包含两路轻量特征投影：

1. **成对音乐参考**：对比已经找到的参考段与当前段之间的语义与起音差异，并保留逐拍可信度、低可信丢弃与真实前文保护，让模型自主学习沿用、变化或不采用参考。
2. **前方采音读取**：在写下一个整数拍时，额外读取前方 `0–1`、`1–2`、`2–4`、`4–8`、`8–16` 拍的音乐摘要；只提供声学证据，不规定每个声学峰都必须落音，也不限制正常休止长度。

两路投影均复用已缓存的音乐特征，不再重新运行 MERT 或新增 Transformer 层，仅增加极少量投影参数。由于新投影采用零初始化，从旧模型微调迁移时会先保留父模型原有的输出行为，再逐步学习新的上下文信息。

## 如何训练“从这段前文接下去”

在整谱预览右侧的「收集训练示范（可选）」面板中：

1. 带前后文试听，在谱面时间轴拖选确认值得学习的一段（如需先修谱，可在 MiaCode 等编辑器修改完整谱面后重新载入）。
2. 选择「只学采音」「只学配置」或「采音和配置都学」。
3. 如果同时认可这一段第一组音符从前文接入的时机，选择只学采音或两者都学后，勾选 **「同时学习如何接入前文」**。
4. 点击「收为训练示范」，再「加入下次训练来源」，与其他可靠训练集一起在**新输出目录**执行 `finetune`。

普通片段只学习所选范围内的内容；勾选前文接入后，还会额外学习从实际前文进入该段第一个事件的选时，而不会给后续其他切分片段额外制造入口，也不会把未确认区间变成学习答案。选择「只学配置」时，首组音符的配置监督本来就会保留，因此无需勾选接入。

该功能不会自动改写原谱，也不会把自动选优结果直接当作优秀示范；训练时输入的是实际前文，目标是人工确认后的续写，从而避免把原谱强行接到不相容的错误前文上。

## 设计边界

- 不引入左右手强制标注、固定段落模板、最低密度限制、有声必落音规则或通用重复惩罚；正常的 16 分与 24 分混用、主动舍音、休止与合理重复均继续由模型从数据中学习。
- 逐键持续占用的额外模型特征目前暂未包含在内，相关能力主要由生成的防锁手检查与物理规则负责。
