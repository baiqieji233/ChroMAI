# Composer v2 短程微调

## 学习率下降

在「训练模型 → 常用训练设置 → 学习率计划」选择曲线。

| 计划 | 走势 |
| --- | --- |
| 余弦下降 | 前后较缓，中间降得快，默认选项 |
| 线性下降 | 每次更新减少相同幅度 |
| 二次下降 | 前段比线性降得快，接近下限时平滑收尾 |
| 指数下降 | 前段下降最明显，后段减量逐步缩小 |
| 全程恒定 | 预热完成后保持设定值 |

在「验证、性能与保存」设置预热更新数、衰减结束步数和最低学习率比例。衰减结束步数从本次训练起点算起，包含预热。到该步降至最低学习率，之后保持。填 0 按总目标轮数计算。只跑少量更新时，可显式设置衰减结束步数与最大更新尝试数。

160 步短测可从学习率 `0.00002`、预热 `10`、衰减结束 `120`、最低比例 `0.1` 开始。四种下降曲线都会在第 120 步降到 `0.000002`。严格续训继承已有曲线和进度。

## 生成前文短测（实验）

选择「已有模型加强训练（finetune）」。在「生成前文短测（实验）」选择「真人前文（对照）」或「生成前文（实验）」，填写同一份本机样本文件。选择包含这些真人谱面的训练素材，填写最大更新尝试数。两组分别使用新输出目录，统一起点、训练数据、随机种子、学习率计划和微调范围。

该模式只使用样本文件中指定的乐句。每段真人后续在两组各学两次，一次共用真人前文，另一次根据组别使用对应前文。训练从原谱的实际后续开始监督，复用该谱的质量标注。生成前文提前准备，训练期间直接读取。它可以帮助个别换配置的段落，已有短测还观察到变奏和休止退化。

### 准备样本文件

在同一录音、拍网和首拍上审阅真人谱及模型输出。选定前文开始拍、真人后续第一个事件的拍位，以及真人后续最后一个事件的拍位。拍位支持整数和分数，结束拍包含在目标内。接缝两侧各准备至少四个真人事件，生成前文也至少四个事件。选择后续确实能接上的例子，包括延续、变奏、换配置和收束。

```sh
python -m maichart.composer_v2.generated_prefix --reference maidata.txt --generated output/maidata.txt --audio track.mp3 --start-beat 36 --join-beat 38 --end-beat 40 --output prefix_bank.json
```

默认读取两份谱面的 Master。可用 `--difficulty` 和 `--generated-difficulty` 指定槽位 4、5 或 6。再次运行并使用同一输出文件会加入新的乐句。训练加载时核对音频与真人谱身份、精确拍位、持续动作和物理可行性。严格续训使用原模式与原样本文件内容。样本文件保存在自己机器上即可。
