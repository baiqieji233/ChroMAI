## 节奏修复思路与实现

原流程独立把每个峰转换成有理拍位，再逐点吸附到最近网格；已落在任一允许网格的点会被跳过。局部错误三连位置因此无法根据周围的均匀节奏纠正。

新的 `sequence` 策略先保留逐点结果，再检查 4～8 个相邻起音是否共同支持一个均匀网格。它要求起音时间具有足够局部规律、候选拍位严格递增、间隔满足预算，并遵守变 BPM、音频范围、显式休止和曲尾边界。允许重新考虑已经落在错误常见网格上的点，已接受的局部锚点不会被后续窗口反复改写。

只有符合条件时才覆盖逐点结果；证据不足时保留逐点处理。候选包含用户选中的 12、16、24、32 及自定义分音，不把全曲固定成 16 分。这是解码层的保守推断，不是新的神经网络学习能力。

位移同时受用户容差约束；局部一致推断还把原始峰误差限制在约 20 ms 和 0.075 拍以内，以降低错误规整真实三连、附点或混合节奏的风险。这不是保证永不误判，真实高 BPM 模糊情况仍需试听。

185 BPM 的轻量复现：

| 输入/策略 | 五个拍位 |
| --- | --- |
| 理想均匀 16 分 | 0, 1/4, 1/2, 3/4, 1 |
| 原始峰时间 | 0, 100, 160, 260, 320 ms |
| 逐点策略 | 0, 1/3, 1/2, 5/6, 1 |
| 局部一致，32 ms 容差 | 0, 1/4, 1/2, 3/4, 1 |

没有增加、删除或合并这五个起音。新日志 `form_rhythm_snap` 记录规整模式、改变数、重新考虑的常见位置、推断网格和位移。

## WebUI 使用

入口：生成谱面 → 全曲规划与段落参考。

1. 启用「近似到常见分音」。关闭时不运行新的局部规整。
2. 「分音规整方式」默认选「局部节奏一致」。需要对照时可选「逐点最近」。
3. 先保持准确 BPM、首拍偏移和现有起音阈值；它们定义音乐时钟，规整不负责修复错误 BPM。
4. 「最大采音偏移」是容差上限。上述复现使用 32 ms；不为恢复均匀节奏突破用户设定的容差。
5. 保留真实 12/24 分候选；16 分附点通常还需要 32 分网格。低 BPM 的 48/64 及自定义分音仍可配置。

CLI 对应 `--rhythm-snap --rhythm-snap-mode sequence`；逐点对照使用 `point`。
主页面、API 与 CLI 均有对应模式。已运行的 WebUI 后端须重新启动才能完整加载新 API，现有训练进程不会热更新。

## 训练与曲线修复

负荷曲线 bins 使用谱面相对秒，有效结尾改为 `audio_duration-first`，并单独过滤音频时间之外的事件。例如 first=-2、音频 8 秒，beat 19 的音符位于音频 7.5 秒，现在会进入尾部监督。

标注查找同时检查源文件路径、难度、谱面内容哈希及可选音频身份。只有哈希而缺少源身份的标注不再随机绑定；需要通过训练素材管理重新保存正确身份。

全曲 Planner 描述固定使用起始区域，避开首个可训练样本因排除或预算超限而漂移的问题。训练语义记录为 `song_form_training_v3`。

准备缓存以相关源码指纹为键，因此这些数据修复会导致下一次启动时重建一次旧准备缓存。已经启动的训练仍使用已加载的旧逻辑；新监督只影响之后启动的训练。现有 checkpoint 的权重不会因为修改代码自动得到纠正。

保存曲线现在核对音频 SHA、checkpoint 权重 SHA、first 及实际解析的 tempo map。输入曲线启用却为空会明确报错。等级、Radar、Style 改变只返回沿用提醒；它们不强迫重新生成曲线。训练中持续覆盖的 form_last.pt 应与固定 epoch checkpoint 区分，覆盖权重后旧曲线需要重新预测。

自动 BPM 与曲线预测使用同一规则，避免同一标准操作下两条链路采用不同速度。实际变速表按精确 beat 与 BPM 绝对容差 1e-6 比较；first 容差为 1e-9，不把浮点表示噪声认作时钟变化。

用户实际反馈的 `lacks identity metadata (tempo_map_sha256)` 是本轮新增校验未考虑前端省略 null 可空字段造成的回归。最新自动曲线本身完整，未设置显式 map 时两个字段应为 null。现在前端保留 `tempo_map_sha256:null` 和 `explicit_tempo_map:null`，校验器也能恢复省略的可空指纹；必须的音频、权重和真实时钟仍核对。这条错误本身不需要重做曲线，刷新页面后在权重/时钟未变的条件下可继续沿用。

超长 note 回退使用可完成的目录配置，替换输出 token、加入结束标记，并回退 KV cache 的错误尾部；不再让下一 note 读取未闭合的虚假前文。
