# 少量数据也能学会常规谱：流式架构的新设计方向

2026-10-30。本文是设计提案，尚未实现，不改动当前 v27 训练。用户已确认对照项目也采用流式生成，因此不能把“逐步输出”本身当成质量差的原因。

## 核心判断

应把“少量优质谱足以学会不错的常规写法”当成设计要求。当前架构需要学习的内容，可能比实际写谱所需的独立决定多得多。

例如 `1/5 → 2/6 → 3/7 → 4/8`，人可以用“保持对向双押，连续转动四次”理解。模型目前主要被要求逐次选具体音符。相对键位分数、统计计划、历史记忆能提供帮助，但它们没有直接把“四次都遵守同一关系”变成可执行的输出。

这不意味着自回归交叉熵必然把多种写法平均成坏谱。足够好的自回归模型可以自行学出这些关系，用户提到的其他流式项目就是重要参照。这里的假设是：我们的表示和训练单位让这种能力学得过于费力。

流式输出与逐事件重新决策是两回事。模型可以先决定一个短段的写法，再逐事件提交；它仍然是流式，也能持续读取新的音频和已提交配置。

## 主方案：让模型选择一个可以执行的短句

把输出单位改为短而可变长的配置片段，首个实验以 1～4 拍、常见的 4～8 个事件为主，二者都不是硬性的音乐小节定义。片段可以为空，也可以因真实边界而提前结束。

一段包含：节奏骨架、完整同拍配置的关系、起始位置、持续长度，以及结尾的少量变化。不是只预测密度、Touch比例等统计，而是直接决定可以展开成 events 的内容。

示意：

```
起点：1/5
事件间隔：0.5拍
动作关系：整个双押集合每次旋转一格
执行次数：4
最后一次：按原谱允许的局部修改
```

这只是表示示例，不是人工规定常规谱必须这样写。候选短句和关系从训练谱自动提取。不能简洁表示的 Hold、Slide、Touch 或复杂组合保留完整原子表达；编译器必须能无损还原原谱。

采样到一种短句后，保留它的执行位置和剩余部分。不能每输出一颗就重新抽取另一种短句，否则又回到逐步摇摆。若需要重新规划，只修改尚未提交的部分；完整段错误也不能被强制执行很久。

这与当前机制的区别是：`quality_context` 给出统计性条件，`phase_echo` 给候选加偏置，短句程序则直接规定输出关系。若该方案成立，它应替换常规片段的逐槽动作展开及部分重叠的 echo/相对关系修正，而不是再叠一个分支。

## 方向一：预测相对配置形状，单独选择它放在哪里

这条可以先于完整短句程序单独试验。

把“配置形状”和“绝对起点”拆开。`1/5→2/6`、`2/6→3/7` 等属于同一种整体关系；模型共享学习它，另一个小决策保留原谱实际起点偏好。多押作为无序集合表达，避免让排序后的第一个槽位替整个配置承担方向选择。

关键是把相对关系作为实际输出，不只是附加到绝对音符上的一个小偏置。原始键位、方向、时值与轨迹仍需精确还原。

可以用循环旋转的规范表示压缩重复模式，但不强制做左右镜像增广、不规定左右手，也不让八个起点等概率。对称双押可能有多个等价锚点，应合并产生同一实际配置的概率，避免为人为选择的锚点重复制造分类难度。Slide/Touch 的几何变换必须经解析器验证；首个版本可以只压缩 Tap、常规双押，把其余完整保留。

收益假设：减少相同常规结构在不同键位被分别学习的次数。主要风险是规范化过度抹掉真实起手习惯、对称姿态存在多种编码，以及复杂滑条变换不等价。

## 方向二：训练样本按时间段建立，让空白成为可预测的内容

目前主要训练样本围绕“下一次真实起音”建立，休止依靠事件率、空隙和 planner 的辅助监督补充。可以试验按短时间段抽样，直接预测这段的事件集合，允许事件数为零。

这样，一段休止不只是两个起音之间的附属空隙，而是主输出中的合法结果。片段内密度、细分族、同拍物量也能共同学习，不必每一步独立重猜。

这同样有计算收益：一段的全曲音频状态和历史编码只需计算一次，再由轻量解码器预测几个事件。当前 `phrase_groups_v1` 只是把相邻目标排在一起，并没有实现这种共享的片段决策。

主损失可以直接学习原谱短段的联合概率，保留段内空白和精确时刻；旧逐事件损失作为对照，不把现有全部辅助目标继续叠到新方案上。空段比例、长短段权重与复杂片段必须显式统计，避免以大量空白换取低损失。

最大的风险是片段边界：Hold/Slide 可以跨边界，多押不能被拆开，当前段必须读取进入时仍在持续的动作。不能在每段开始时把身体占用状态清零。

## 方向三：让模型持续选择“在跟哪条音乐线索”

用户说“这里应该安静些”，不一定意味着音频能量接近零。旋律可能暂停，但底鼓和伴奏仍在。如果模型只学到混合音频强度与物量相关，就可能跟着剩余伴奏继续铺音。

值得试验的不是再调一个响度阈值，而是让一个短段保持相同的音乐关注点：主要跟瞬态节奏、旋律变化还是持续声音。在该线索暂时停顿时，允许谱面跟着停顿，而不立即跳去追另一条还在响的线索。

先复用现有音频编码器，以极少量读取方式表达关注差异；不先引入昂贵的人声/鼓组分离网络，也不要求用户提供声部标签。谱面真实落点与空白可用于训练片段级选择，但不能声称没有标注就一定能自动分离真实乐器。

必须防止所有读取方式学成同一种东西，或仅按难度控制物量。最小验证可以用声部清楚的歌曲或受控混合音频：保持伴奏、只移除主旋律片段，看配置是否保留该段的休止倾向。这个方向与“总体事件率预测得准”不同，目标是学会有选择地采音。

## 方向四：把已经写好的短句当作可以调用的记忆

当前长程动机检索依赖音频关联，phase_echo 需要从近期几个事件里积累证据。可以改为归档已经完成的短句程序：写法、节奏骨架、入口/出口、对应音频上下文。

之后预测的动作可以是“新写”“调用已有短句”“调用后改结尾”，而不仅是再次从音符词表开始。音频决定是否呼应、是否增强、是否留白；程序负责保持被选中的结构。

不要求两次副歌波形相似到超过某个固定阈值，也不预先赋予主歌副歌标签。旋律相似但编排不同的两段，仍可能调用同一种配置关系并改变节奏、位置或末尾。

调用必须有有限长度和明确返回点；这不是给最近的 18/45 交互不断加分。风险是反复调用同一个短句造成机械模板化，所以必须同时测复用质量、变化位置和长段回环，而不是只追求呼应比例增加。

## 更大胆的训练安排：先学写法，再学如何配乐

第一阶段可以只用已有谱面建立短句表示、学习常规结构与衔接，不承担全曲音频准备成本；第二阶段学习根据音乐、难度和已完成短句选择写法；最后才联合微调。

这里必须明确分工：谱面语法提供可用的写法，音乐选择器决定何时使用、用多少以及是否休止。不能训练出强大的历史复制器后，继续期待很弱的音频辅助项自然纠正它。

这种拆分也更适合研究“少量数据为什么够用”：少量谱包含很多重复的常规动作关系。只要表示能共享它们，模型不必反复学习每一种绝对键位组合。第二阶段要验证音频打乱或替换会改变选音和片段安排，避免程序语言很漂亮、实际仍不听音乐。

## 实验顺序

先保留当前 v27，以下实验不需要立刻终止它。

1. 不训练，验证常规谱能否被少量短句操作无损表达。包含所有引用、起点、长度和补丁成本，不能只计算字符串压缩率。字典只从训练歌曲提取，开发歌曲不能泄漏。若常规片段大多仍需逐音字面表达，说明主方案缺少足够收益，应改表示而不是直接重训。
2. 固定同一批少量歌曲、开发集与音频编码器，对照 A 当前逐事件；B 直接预测短段原始事件；C 预测可执行短句。B 能区分收益来自计算共享和预测跨度，还是来自程序表示。同时约束训练时间、模型规模并报告实际监督的事件数量。
3. 第一轮只覆盖常规单押/双押，复杂部分仍无损表达。比较固定音频多种子的完整谱、休止、双押成员连打、段落边界和局部连续性；安排听音与试玩。不能因 literal 回退较多就偷偷删除难例。
4. 只有短段路线有收益后，再测试持续音乐关注点和历史短句调用。不要一次把所有想法加进同一模型，导致无法判断哪一项有效。

优先建议：**相对配置表示 + 持续短句决策**。这两项直接减少常规配置需要独立学习和重复采样的次数。时间段监督紧随其后；音乐关注点是专门针对“伴奏仍响、主线该休息”问题的独立质量实验。

## 外部思路的来源与界限

[ACT 原论文](https://arxiv.org/abs/2304.13705)在机器人模仿学习中预测动作片段，研究用少量演示学习连续行为；[VQ-BeT 原论文](https://arxiv.org/abs/2403.03181)研究把动作或动作片段编码成可预测的离散表示。这些工作提供跨领域启发，并不能证明谱面采用同样方案就会成功。不能直接对离散音符照搬连续动作的平均融合，也不需要先堆 VQ-VAE、扩散采样等复杂部件；首版可从可解释、无损的短句表示开始。
