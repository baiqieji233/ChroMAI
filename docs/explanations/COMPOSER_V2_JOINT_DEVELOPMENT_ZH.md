# Composer v2 音乐与写法联动训练

在 WebUI 的「训练模型」选择 Composer v2，展开「音乐与写法联动训练」。这组设置随训练任务提交，在主界面直接可见。

| 设置 | 默认 | 实际作用 |
| --- | --- | --- |
| 音乐与写法联动学习 | 自动 | 利用已缓存的音乐特征，给原谱里与音乐的延续、渐变、转换或留白有关的片段额外监督权重。 |
| 乐句强化上限 | 0.30 | 原有监督保留。额外权重最多占强化后总监督的 30%，实际份额随素材变化。0 表示保留原权重。 |
| 局部写法学习 | 自动 | 从头训练及连续事件模型微调采用 `audio_writing_v3`。从音乐预测前方 0–2、2–4、4–8 拍里的动作走向、起手、持续占用和释放衔接。模型按事件连续写谱。 |
| 写法学习权重 | 0.05 | 按这个系数把预测损失加入训练总目标。 |
| 微调范围 | 自动 | 自动使用「全部参数」。选「音乐读取连接」时，主要更新解码器读取局部与全曲音乐的连接、成对参考与入段预览连接，以及写法预测分支。 |

新版在有监督的拍位学习真实谱面的动作。训练和生成均使用从音频预测的写法。旧版的「未来配置预判」可用于对照，其辅助任务只影响训练，约 25% 的常规训练片段尝试加入该练习。

- **从头训练**时保持自动即可启用两项学习。生成会使用检查点已学到的动作与起手预测。
- **用已有连续模型学习这两个目标**时，选「已有模型加强训练（finetune）」，指定原 checkpoint 和新的输出目录。自动会启用两项学习。可以从同一检查点分别开启和关闭这组学习，用两份新目录做对照。
- **断点续训**沿用原训练目标、权重、微调范围和优化器状态。此前未启用的检查点按关闭续训。旧的固定窗检查点可按旧路线续训和生成。

训练任务会记录启用的策略和写法预测损失。可用相同歌曲、定数、种子和生成选项对照两份模型，试听完整谱面的保持、渐变、转段和休止，并试打确认动作衔接。短训结果和评估入口见 [动作走向、候选选优与整谱评价](COMPOSER_V2_MOTION_AND_REVIEW_ZH.md)。
