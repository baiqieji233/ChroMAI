# Composer v2 音乐与写法联动训练

在 WebUI 的「训练模型」选择 Composer v2，展开「音乐与写法联动训练」。这组设置随训练任务提交，在主界面直接可见。

| 设置 | 默认 | 实际作用 |
| --- | --- | --- |
| 音乐与写法联动学习 | 自动 | 利用已缓存的音乐特征，给原谱里与音乐的延续、渐变、转换或留白有关的片段额外监督权重。 |
| 乐句强化上限 | 0.30 | 原有监督保留。额外权重最多占强化后总监督的 30%，实际份额随素材变化。0 表示保留原权重。 |
| 局部写法学习 | 自动 | 从头训练及连续模型微调沿用动作走向与起手（v3）。选「乐句衔接与留白（实验）」可测试空拍取样、出音间隔和下一组配置。断点续训继承检查点。 |
| 写法学习权重 | 0.05 | 按这个系数把预测损失加入训练总目标。 |
| 微调范围 | 自动 | 自动使用「全部参数」。选「音乐读取连接」时，主要更新解码器读取局部与全曲音乐的连接、成对参考与入段预览连接，以及写法预测分支。 |

新版在有监督的拍位学习真实谱面的动作。训练和生成均使用从音频预测的写法。旧版的「未来配置预判」可用于对照，其辅助任务只影响训练，约 25% 的常规训练片段尝试加入该练习。

- **从头训练**时保持自动即可启用两项学习。生成会使用检查点已学到的动作与起手预测。
- **用已有连续模型学习这两个目标**时，选「已有模型加强训练（finetune）」，指定原 checkpoint 和新的输出目录。自动会启用两项学习。可以从同一检查点分别开启和关闭这组学习，用两份新目录做对照。
- **断点续训**沿用原训练目标、权重、微调范围和优化器状态。此前未启用的检查点按关闭续训。旧的固定窗检查点可按旧路线续训和生成。

训练任务会记录启用的策略和写法预测损失。可用相同歌曲、定数、种子和生成选项对照两份模型，试听完整谱面的保持、渐变、转段和休止，并试打确认动作衔接。短训结果和评估入口见 [动作走向、候选选优与整谱评价](COMPOSER_V2_MOTION_AND_REVIEW_ZH.md)。

### 乐句衔接短测

在「音乐与写法联动训练」的「局部写法学习」中，可先选「空拍与重音位置」（`audio_grid_v4`），用 `0.05` 的写法学习权重微调。它在原有按拍写法上补充空拍取样、出音频率以及首个双押、Break 或非 Tap 配置的位置。每段最多额外读取两个整拍的缓存音乐特征。用已有连续事件模型时选微调和新输出目录。

「乐句衔接与留白（实验）」（`audio_writing_v4`）包含上述修复，另从实际落键的时间和已经写出的配置预测下一组动作。模型学习是否延续当前键位走向，是否出现双押、Hold、Slide 或 Touch，以及距下次出音是否达到半拍、一拍或两拍。时间和配置预测分别在相应的解码步骤参与选择。新接线从零输出开始。训练只在可信的标注范围内计算对应损失。

「前文纠错训练」可单独选「节奏与配置衔接（实验）」（`causal_layout_v2`）。部分已有纠错片段用模型在真实前文上的预测替换 1–3 个单 Tap 键位，拍位、最后两键和后续目标保留。无合适片段时沿用节奏纠错。运行面板显示试写键位数和实际改写数。这一项只增加训练练习。

对照时从同一原检查点、在不同目录用相同素材和更新数微调。先单测局部写法，再加入前文纠错。用留出歌曲连续生成短段，同时检查合理重复、配置转折、停手后的再次进入，并对照出音量。

以同一原检查点进行的两组种子短测中，每组训练 128 次更新。固定已训练权重、只切换额外的动作预测接线后，48 对短段续写的事件序列相同。现阶段可以单独使用取样修复，完整预测分支与试写保留为实验选项。
