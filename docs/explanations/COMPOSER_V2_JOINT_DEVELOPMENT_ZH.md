# Composer v2 音乐与写法联动训练

在 WebUI 的「训练模型」选择 Composer v2，展开「音乐与写法联动训练」。这组设置随训练任务提交，在主界面直接可见。

| 设置 | 默认 | 实际作用 |
| --- | --- | --- |
| 音乐与写法联动学习 | 自动 | 利用已缓存的音乐特征，给原谱里与音乐的延续、渐变、转换或留白有关的片段额外监督权重。 |
| 乐句强化上限 | 0.30 | 原有监督保留。额外权重最多占强化后总监督的 30%，实际份额随素材变化。0 表示保留原权重。 |
| 连续配置预判 | 自动 | 从同一个写谱位置学习后续第 2、4 个事件，以及接下来 0–2、2–4、4–8 拍内的配置。目标来自真实谱面，包括音符种类、位置、按钮移动、持续动作和留白。拍数只用于训练监督的观察范围，模型仍按事件连续写谱。 |
| 预判学习权重 | 0.05 | 预判损失以这个系数加进训练总目标。设为 0 时预判损失没有贡献。 |
| 微调范围 | 自动 | 自动使用「全部参数」。选「音乐读取连接」时，主要更新解码器读取局部与全曲音乐的连接、成对参考与入段预览连接，以及启用的预判分支。 |

训练时，约 25% 的常规训练片段会尝试加入预判练习。实际加入预判的片段保留训练定数、当前音乐和已经发生的谱面，隐藏从整张原谱算出的可选 Radar / Style 和原谱强度提示。其余片段继续学习原来的条件。

- **从头训练**时保持自动即可启用两项学习。预判只在训练时计算。生成仍使用原有 Composer v2 工作流，训练会借由共享参数影响写法。
- **用已有连续模型学习这两个目标**时，选「已有模型加强训练（finetune）」，指定原 checkpoint 和新的输出目录。自动会启用两项学习。可以从同一检查点分别开启和关闭这组学习，用两份新目录做对照。
- **断点续训**沿用原训练目标、权重、微调范围和优化器状态。此前未启用的检查点按关闭续训。旧的固定窗检查点可按旧路线续训和生成。

训练任务会记录启用的策略和预判损失。要判断写法是否更贴合音乐，可用相同歌曲、定数、种子和生成选项对照两份模型，试听完整谱面的保持、渐变、转段和休止，并试打确认动作衔接。
