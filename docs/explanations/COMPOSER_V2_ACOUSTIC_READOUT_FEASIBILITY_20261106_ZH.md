# 独立声学读出：哪些已经可行，哪些还不能直接用于生成

日期：2026-11-06。对象：Composer v2 连续事件路线及 v6 的 44,200 步检查点。

## 结论

**可以低成本地补出一条更直接的起音参考，但不能把起音分数直接当成下一颗音符的概率。**

《Strange Bar》里，模型被前文带偏的四处落点，独立小网络全部更支持官谱所用的实际起音。换两个初始化种子后，四处仍全部成立。这证明目前的声学输入里存在可用的信息，问题不只是音频特征不够精细。

但是，跨歌曲的16分／24分混合辨别仍不够稳定。只按起音分数选时间，还会追逐别的声音、重复选择前一颗音的起音尾部，或在正常留白里要求出音。因此本轮只保留实验与证据，没有把实验分数接进正式生成，也没有改动训练目标、WebUI 默认值或原检查点。

## 实际做了什么

训练数据沿用上一轮已经选好的小样本清单，去重后为 **63 张谱、63 份音频**。验证使用 v6 开发集，去重后为 **48 张谱、38 份音频**，两者没有相同的音频哈希。

实验复用了已有的100 Hz声学缓存：96维频谱、频谱变化、能量，共98维。没有重新提取 MERT，也没有把谱面前文交给独立读出。每个候选读取前后各200毫秒的音乐，经过约 **2.81 万参数**的小卷积网络得到一个分数。读取候选后方的音乐符合离线写谱条件，不读取未来谱面。

比较了四种方法：

1. **现有频谱变化分数**：直接用缓存，无须训练。
2. **独立落点比较**：学习把官谱落点排在附近另一种16分／24分位置之前。
3. **独立出音分类**：同时用官谱落点和没有新事件的位置训练，包含有声留白。
4. **提高少数分音覆盖**：让落点比较的训练批次等量包含16分、24分和其他间隔，检查单纯增加24分训练机会是否有效。

每组均为400次小网络更新。另用外部已有的 DDC 起音检测器做了对照。没有给完整 Composer 追加训练。

这里的“正确”只表示：在给定官谱落点和一个附近备选之间，更支持官谱落点。官谱没有选某个声音，不代表那个声音不存在；这些分数不能直接解释成音乐质量或整谱24分召回率。

## 结果

### 用户指出的四处位置

这四处来自《Strange Bar》约30—35秒，BPM 110、首拍偏移0，与此前交付的谱面和音频一致。

| 更贴近原谱起音的位置 | v6 当时选择的位置 | 独立落点比较 | 原始频谱变化 | 外部 DDC |
| --- | --- | --- | --- | --- |
| 30.727秒 | 30.682秒 | 更支持正确位置 | 更支持正确位置 | 更支持正确位置 |
| 31.545秒 | 31.500秒 | 更支持正确位置 | 更支持正确位置 | 更支持正确位置 |
| 32.091秒 | 32.045秒 | 更支持正确位置 | 更支持正确位置 | 更支持正确位置 |
| 34.182秒 | 34.227秒 | 更支持正确位置 | 更支持正确位置 | 更支持正确位置 |

独立落点比较的三个初始化种子都得到4/4。原 v6 根据生成前文重建的查询，对第二、第三处正确位置只分配约 `4.0e-7`、`5.0e-8` 的概率。该重建不是原生成过程的逐步日志，不能声称复现了当时每次重试的缓存状态；它说明的是相同音乐下，生成前文可以极强地压制正确候选。

### 跨歌曲的辨别能力

| 方法 | 16分相关候选对：2,489组 | 24分相关候选对：583组 | 附近同时含16分和24分：192组 |
| --- | ---: | ---: | ---: |
| 现有频谱变化 | 94.1% | 65.9% | 65.1% |
| 独立落点比较，种子1106 | 93.9% | 66.6% | 61.5% |
| 独立出音分类 | 96.0% | 61.7% | 62.0% |
| 等量训练不同分音的落点比较 | 91.0% | 67.1% | 66.1% |

独立落点比较另外两个初始化种子的24分结果为67.8%、67.6%，混合结果为64.1%、64.6%。**当前小网络没有稳定胜过现有频谱变化特征。** 等量训练略提高部分混合辨别，但损失了16分准确率，不能据此调整正式训练采样。

混合子集仅来自8份音频，按歌曲重采样后的区间较宽。例如独立落点比较第一种子的95%区间约52.8%—78.2%。不能把几个百分点的差异当成可靠胜出。

外部 DDC 对照用了此前四首歌的六张开发集谱面，共2,285组候选对：24分相关候选为69.7%，混合为61.9%；同一子集的现有频谱变化分别为69.0%、53.6%。它提供了额外证据，但没有形成足以替换现有特征的总体优势。这里的六张谱与此前只展示的四张参考谱口径不同，不能直接混算。

### 正常休止为何必须单独保留

在857个“音乐仍有能量、官谱至少一秒没有新事件”的抽样位置上，以训练集90%真落点召回对应的阈值计算：

- 独立落点比较有43.4%的位置仍超过阈值。
- 加入空白样本训练的出音分类降至20.2%，仍不能独立接管出音。
- 只强化少数分音的比较模型，绝对分数更加失去标定；其相对比较改善不能解释为更懂休止。

这些是给分行为，不是实际生成多写音符的比例。没有新事件也不等于没有动作，部分空隙可能仍有 Hold／Slide 在持续。

数学原因很直接：**“A位置比B位置更像起音”的训练，没有要求模型回答“这里到底应不应该写音符”。** 两个问题必须协作，不能共用一个未经校准的阈值。

## 为什么不能直接加一个“按波形写谱”滑块

当前 v6 有532个拍内时间符号，其中很多分数落在同一个10毫秒声学帧附近。《Strange Bar》的一个整拍内，531个可用符号只对应55个10毫秒位置；正确位置前后10毫秒内就可能有19—20个符号。

本轮实际做了一个反例：让独立起音读出单独给所有合法拍内符号评分。上面四处的最高分变成了 `1/128`、`95/96`、`191/192`、`95/96`，而不是原谱位置。主要原因是它追到了其他更强起音或前一颗起音的余部，并且不能独立解决密集分数符号之间的分配问题。

这不构成禁用这些分音的理由，也不是现有生成器已经采用这种算法。它排除了“检测器分数直接 softmax，然后替换选时”的接法。

简单追加一个小偏置也未必够。在四处复现中，v6 错误候选领先正确候选约5.5—16.8个对数分数单位；这次小读出的正确信息不足以用统一的弱偏置全部推翻它。盲目放大又会牵动其他歌曲。因此需要正式微调来学习双方的分工，而非只调一个推理系数。

## 建议推进的接入方案

优先补充**候选落点的声学比较**，保留现有连续事件生成器、配置上下文和编排选择。

1. **独立读出音乐证据。** 从现有100 Hz缓存读取候选附近的瞬态及频带变化。整段音频共享计算，避免每个音符、每个候选重复编码。MERT继续提供音乐背景，瞬态读出承担更细的位置比较。
2. **把证据送到真正选时间的地方。** 首轮以已经选定整数拍后的拍内决策为明确范围，训练和生成走同一接口。候选的声学分数与已有时间先验共同训练，不能把检测到的峰直接硬吸附成音符。
3. **保留连续编排。** 新证据只参与时间决策；已写配置、Hold／Slide状态、当前手法仍由原模型读取。只改变采音依据，不整体削弱历史。仍然要验证时间改变后是否给配置衔接带来连锁影响。
4. **保持16分与24分混用。** 对每个落点进行比较，不为整段音乐选一个不可改变的分音家族。训练使用真实混合片段和附近备选，并保留原始样本。避免仅凭重采样把模型推向24分。
5. **保留主动留白。** 起音比较不自行增加事件、提前结束休止或修改EOS概率。首轮仅在同一前文、同一整数拍条件下重分配拍内概率；这只能保证该次条件分布的范围，不能保证整首自回归生成的物量完全不变。
6. **不把拍内改善冒充入口恢复。** 只接拍内分支不能解决整拍已经跳过的情况。若后续验证入口遗漏仍多，再把同一声学证据接到整数拍候选与休止联合决策，必须一并验证留白，不能只补一个有声必写分支。
7. **保留 v6 微调能力。** 使用新的显式能力标记，原词表和原权重保留；关闭新分支时复现原输出。完成新分支训练后，才考虑在主界面暴露“起音参考强度”。它应只调整采音依据，不能同时改变配置大胆程度或音符数量目标。

这份建议是下一步实现合同，不代表以上接线本轮已经上线。不能仅凭4处候选比较改善宣称完整谱面已经变好。

## 其他方案的取舍

| 方案 | 本轮判断 |
| --- | --- |
| 先用现有频谱变化作轻量声学参照 | 值得优先考虑。已能区分四处目标，几乎没有新增特征成本；仍需学习与模型先验的配合。 |
| 外部预训练起音模型 | 保留为对照或辅助输入。已有实测支持，但未证明优于现有特征，不立即增加正式依赖。 |
| 短段内比较多种采音方案 | 有价值。可以比较同一音乐片段的局部节奏解释，避免逐点只追最大峰；评分必须保留合理的舍音与留白。尚未做整谱生成验证。 |
| 只增加 MERT 容量、音频层数 | 不是本轮证据支持的优先项。现有缓存已包含能区分目标的信息。 |
| 再扩大错误前文恢复训练 | 单独不足。上一轮未达到生成验收标准；本轮也证明需要更直接的声学比较依据。 |
| 强制跟峰、禁止混合分音、按有声长度补音 | 不采用，会改变原本允许的编排自由。 |
