# 整曲写法与短句关联：本轮维护说明

本轮基于 v41 的完整短句训练继续修改。目标是让同一张谱前后保持可辨认的写法，同时随音乐变化；没有人为划分曲风，没有加入同曲多谱对比训练。

## 改动原因

此前普通生成通常只指定等级，其余整体倾向使用默认值；训练却使用各张真实谱面自己的统计条件。另外，短句可以分别选择写法，但缺少共同解释远距离几句的学习目标。

因此本轮补上两个相互独立的能力：根据音乐补全整体倾向，以及在整曲中保持一种“遇到不同音乐如何选择短句写法”的响应方式。两者都可以单独关闭做对照。

## 已实现的路径

1. **自动补全整体倾向。** 使用已有全曲音频摘要、等级、用户明确指定的字段和已知字段标记。用四分量、129 档的联合混合分类分布学习被遮住的真实条件，在曲首采样一次。主动作训练仍使用原谱对应的条件，避免随机风格被强迫拟合唯一原谱。
2. **参数自身保持一致。** 双押的重复字段绑定；Tap、Slide、Hold、Touch、TouchHold 作为五类互斥基础比例，Hold 与 Touch 的界面比例允许共同包含 TouchHold。采样后在满足明确锁定项的可行范围内投影。这里只处理参数定义，不决定某一拍必须写什么。训练分数是投影前的离散分布分数，不能当作投影后分布的精确似然；129 档也不代表音符时值被量化。
3. **整曲响应选择。** 曲首从全曲音乐与条件选择一个内部响应模式。每句以局部音乐、全曲音乐、两者差异和全曲位置，结合已有短句意图，计算四种短句写法的选择概率。内部编号没有“滑条流”等人工语义。
4. **同谱远距分组。** 从同一批次的同一张谱选取 2–4 个完整、可信、分散的句子，共享整曲响应模式。不同难度即使共享音频也绝不合并。先累计句内每种写法的分数，再计算跨句的共享选择。它替换相应配置目标，不重复增加一份动作交叉熵。
5. **参考可以使用或放弃。** 已完成参考的匹配程度进入原有参考变换选择的小网络，允许学习旋转、镜像或新写。没有固定相似度门槛，也没有强制复用随机数来制造重复。
6. **回退状态一致。** 整曲条件与响应选择在一次生成中保持不变。搜索分支和历史撤回继承它；恢复采样的跨轮次 episode 保存它。局部模式仍按真实保留的前缀重建。

## 训练效率与边界

整曲响应只改变短句模式先验，不进入主干或动作执行张量，因此共享原有四种短句得分，不把事件级前向扩成十六份。全曲投影复用编码缓存；条件补全网络在每批次每张谱只执行一次，避免按窗口重复计算。训练时不进行 CPU 条件投影，也不逐步重建音频特征。

跨句目标是小组复合目标，不是整首谱的精确联合似然。原始事件权重与有效目标归一化保持；整曲先验每组计一次。分组大小改变共享选择范围，因此不能宣称改变组大小后目标严格不变。

风格辅助项按批次中唯一谱面的平均损失计入，并单列 `song_profile_loss`、`song_profile_weighted_loss`。同一谱跨多个批次仍会再次学习，不称作每轮每谱仅计一次。训练目标版本为 `stream_song_response_joint_v6`，总 loss 不宜直接与 v41 比较。

首期重点是配置组织。新的整曲响应不直接修改选时、NOTE/WAIT/EOS 或休止控制；配置变化仍可能经后续历史间接影响节奏。没有加入补足 Touch/Slide 数量的配额，也没有新加重复惩罚。这些边界不能代替闭环产出验收。

## 主界面操作

新训练的“整曲风格训练”位于高级学习设置中：

| 控件 | 新阶段默认 |
|---|---|
| 整曲风格学习 | 自动，解析为启用 |
| 音乐响应学习 | 自动，具备新版持续短句时启用 |
| 风格分量数 | 4 |
| 风格学习权重 | 0.1 |
| 响应模式数 | 4 |
| 响应分组大小 | 4，允许 2–4 |

生成页按检查点能力显示“整曲风格”。“自动匹配音乐”仅使用新训练过的补全器；“沿用检查点默认”和“手动设置”保留既有偏好。高级项允许设置风格随机种子、手动锁定 JSON 和音乐响应模式。通常保持自动模式（响应编号 -1）。

部分锁定示例：`{"touch_bias":0.04,"chord":0.25}`。不要同时把 `chord` 与 `chord_bias` 设成不同值。自动模式下普通默认滑块不被当作显式锁定；需要固定的字段写入锁定项。用户提供的完整条件文件按原样使用；WebUI 自动创建的默认快照单独标记，不阻止自动补全。

旧检查点缺少这些模块时保持旧行为，不能仅更新源码就期待 v41 已经学会整曲响应。新训练阶段才能学习新增参数。重启 WebUI 后台后才能加载新控件合同。
