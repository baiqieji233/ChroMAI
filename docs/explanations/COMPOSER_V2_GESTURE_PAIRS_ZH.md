# Composer v2 同曲配置走势对照

用于研究同一段键位前文在什么音乐位置应该延续、在什么位置应该转折。这个选项只改变训练。已有检查点的生成方式、候选选优和温度均沿用原设置。

## 怎样启用

在「训练模型 → Composer v2 → 常用训练设置」中，把「前文纠错训练」选择为「同曲配置走势对照（实验）」。命令行对应 `--timing-recovery gesture_pairs_v1`。「自动」仍沿用原节奏纠错，断点续训继承已保存的策略。

用已有连续事件检查点时，选择「微调」并新建输出目录。从同一个检查点开两组，保持训练集、局部写法学习、微调范围、学习率及更新数一致，只改前文纠错选项。首次短测可使用学习率 `0.00002`。不需要改变「音乐独立练习比例」或「写法学习权重」来启用本项。训练面板的「本次配对练习次数」包括重复使用的样本。

## 训练信号

- 在同一张真人谱中寻找两个不重叠的位置。两边的前四个单 Tap 键位相同，最近拍距相同，实时间隔匹配到毫秒。近期已有持续占用或标注范围不可信的位置跳过。
- 观察后续四个音头，辨认沿外圈相邻移动、两键交互、同键纵连，以及明显的复合配置。一边继续原走势，另一边转成不同走势，或以复合配置起手且四个音头中至少两处为非单 Tap。孤立重音及不确定的过渡可以不参与。换一套键继续同类手法，或仅从 16 分改为 24 分，都不足以作为转折依据。这里识别的是可观察的轨迹，不推断玩家左右手。
- 在两处音乐上比较同一组**三个事件**的原走势续写。使用相同相对拍距、键位和语法预算，直接比较现有解码器给音符类型、键位、单音符结束、同拍结束的联合条件概率。三个事件取平均。比较项希望延续段比转折段更支持这组写法。转折处的假想续写只用于比较，常规逐 token 损失只使用两侧真实的首个出音时刻。原有普通样本仍按真人谱训练。
- 配对练习复用一部分原节奏纠错名额。没有合格配对时回到原节奏练习。不新增模型参数，不在训练中在线生成整谱，也不训练模型把任意走偏的手位强拉回原键。模型自行生成较长前文后的恢复效果需要另行验收。

## 日后复验

2026-11-19 的有限对照从 Kaleidoscope 第 2 轮同一权重开始。在同样的真人谱片段和配对输入上各更新 96 步，只切换配对损失。训练集内区分延续与转折的损失由对照的 0.588 变为 0.570。用四对留出乐句、两组生成种子连续续写，正确延续由 3/8 变为 2/8，转折均为 0/8。另取四段休止，收束后重新进入均为 1/8。当前建议把它作为可复验的训练选项，正常长训仍使用自动。按键号变化或训练损失下降均不足以判断配置改善。

保存起点检查点、训练合同、生成 seed、拍网和生成设置。按歌曲划分留出集。从分岔之前开始连续生成，同时比较应该延续、应该转折、应该留白并重新进入的片段。另记录出音数、真实间隔和持续动作。只换键、只减物量、打断了合理重复，均不能算作配置改善。

下面的命令按同一录音的秒数对照两张谱。选择要审阅的分岔时刻，可一次给出多个秒数。

```sh
python -m maichart.composer_v2.gesture_audit --reference reference/maidata.txt --generated generated/maidata.txt --at-sec 31.7 120.4
```

默认读 Master（槽位 5），可用 `--reference-slot`、`--generated-slot` 分别指定。工具以离指定秒数最近的真人谱音头为界，取前后各四个真人谱音头覆盖的时间，在两张谱各自的 BPM 和首拍偏移下比较。输出四音头滑动统计、复合动作、拍距与实际毫秒数。密度不同会改变统计个数。未分类的写法留给人工判断。没有新音头时还需在预览中核对 Hold 或 Slide 是否仍在持续。
