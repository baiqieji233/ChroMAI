# 审阅、标注和训练示范：按界面顺序操作

这套功能用来回答两件事：哪些写法值得模型继续学，哪些内容应少学或暂时不学。

**浏览、标注、导入和导出都不会启动、暂停或改变正在运行的训练。** 新标注用于下一阶段训练；准备好了再选择来源、应用清单，并在新目录进行 finetune。当前任务仍使用启动时确定的数据和参数。

## 1. 先判断正在看哪一种资料

| 界面里的资料 | 未标注部分如何处理 | 人工确认在哪里做 |
| --- | --- | --- |
| 普通训练集 | 原本就在学习，质量标注调整对应权重 | 打开来源 → 预览与标注 → 圈选 → 记录意见 |
| 候选库 | 只作前后文，未确认部分不学习 | 挑选可学习内容 → 开始／继续审阅 → 这段学什么 |
| 模型生成的完整谱面 | 不会因为生成出来就加入训练 | 完整谱面预览 → 收集训练示范 |

一首谱只有部分写得好很正常。请选一段完整手法，尽量包含进入、展开和收束，不必把整首评为优秀。正常休止、舍音、重复和 16／24 分混用，都可以是好写法。

## 2. 候选库扫描完成后，怎么处理三种结果

在「训练素材」点击候选库卡片，进入谱面目录。上方「挑选可学习内容」可以选择**自动检查状态**。目录里的「查看检查提示」可展开具体原因。

| 自动结果 | 先做什么 | 随后如何处理 |
| --- | --- | --- |
| **错误** | 查看缺文件、缺等级、解析失败、音频无法读取等具体原因 | 先修正原目录中的资料，再点「重新扫描／同步」。修正前不确认学习；也可以留着以后处理。 |
| **待核对** | 查看偏移、变速、冲突或近似已有谱等提示，再带前后文试听 | 对齐正确、写法成立的片段可以确认；需要修谱的先修正再同步。拿不准可以「先看下一张」，或将「这段不学习」。 |
| **低风险** | 扫描未发现问题，继续听采音、看衔接和手顺 | 只确认认可的片段。低风险不等于优秀，也不等于整首自动通过。 |

自动提示不能代替实际试听。比如复杂高难写法可能触发冲突提示，但确实成立；偏移有疑问时，要先确认音频与谱面对齐，不能用「只学配置」绕过对齐问题。

这三类数量是自动检查结果，人工确认不会把「待核对」改写成「低风险」。人工进度看「已确认」和保存列表。自动队列提供代表性、复杂或随机抽查片段，不代表覆盖了整首；其他位置可以自行圈选。

### 实际审阅顺序

1. 选择「待核对」或「低风险」，点 **开始／继续审阅**。也可以直接在目录点 **预览与标注**，自己找想看的位置。
2. 在预览中播放歌曲，查看完整谱面。建议范围只用来定位；可以在**谱面时间轴拖动圈选**，不必手填秒数。
3. 保持前后文试听，判断这一段是否踩准音乐，手法是否连贯，长按／滑条是否影响后续动作。
4. 按认可的内容点一个按钮，**点击即保存**：

   | 按钮 | 模型会学什么 |
   | --- | --- |
   | 这段都学 | 选中的落点、取舍、键位和动作 |
   | 这段只学采音 | 认可出音时机与取舍，暂不学这段的配置选择 |
   | 这段只学配置 | 认可键位与动作；选时不由这段监督 |
   | 这段不学习 | 取消这一段的学习确认，保留谱面和前后文；不是反向训练 |

5. 如果连同前文听过，也认可第一组音符如何接入，勾选 **连同进入这段的第一步一起学**。默认不勾；它不是「整段开始学习」的开关，只决定是否额外学习从前文进入本段的选时。只学配置时不需要。
6. 「保存后自动继续审阅」默认开启；也可关闭，留在同一张谱上继续调整。点「撤销上次保存」可撤销刚才那次操作。

**不必逐段标完整首。** 预览右侧「整谱处理」提供：

- **整张学习…**：将当前难度整张谱的采音与配置用于学习，替换原有片段选择，不再推荐本谱片段。
- **整张不学习…**：取消这张谱已有的学习范围，不再推荐本谱片段；保留源文件，可撤销。
- **先看下一张**：不更改标注，只换一张待审谱面。

自动继续开启时，片段保存后看下一段，整谱决定后看下一张。关闭时停留在当前谱面。误操作可以点「撤销上次保存」；日后也可从目录重新打开，确认新的学习范围。

### 确认后怎么启用

在预览右侧或候选库目录点 **将已确认内容加入下次训练**。页面会勾选该候选库并开启「使用已保存的质量标注和训练示范」；其他可靠来源可一起使用。若对应原训练集也已勾选，界面会询问是否改为只用候选库，避免原整谱内容重新进入学习。

随后到「训练模型」检查所选来源，选择新目录进行 finetune 或 fresh，再开始训练。新增标注不会立即改变现有模型，也不改变当前训练；无需额外的候选库启用开关。

## 3. 怎样人工审核已有训练集

1. 在「训练素材」点普通训练集名称，搜索歌曲，再点 **预览与标注**。
2. 在上方预览打开完整谱面，沿时间轴播放、拖选范围；上一张／下一张可连续浏览。
3. 用「记录意见」中的 **好／有问题／不确定** 保存片段标注。「评价方面」可选采音、配置或手感。
4. 右侧 **已保存的标注** 会立即更新，点击范围即可返回试听。

普通训练集和候选库的区别是：普通训练集未标注的内容原本仍会学。好片段可以加权，问题片段可排除对应分项，不确定的内容保持普通基线。若只想学习人工挑出的部分，请先建立候选库，或者把确认的好片段导出后作为示范库使用。

目录中的整谱「优秀／普通／减权／排除」和批量权重用于调整原来源的整体学习份额。**整谱标签不会自动变成一组亮眼片段。** 要导出片段，请在时间轴明确圈选并保存「好」；只认可采音或配置时，选择对应的评价方面。

问题标注本身没有提供正确写法。需要教模型如何改时，可先在 MiaCode 中改好完整谱面，再载入修改后的版本，确认其中值得学的范围。

## 4. 怎样收集生成结果中亮眼的部分

1. 生成完成后，在「生成谱面」顶部预览选择一张**完整成品**，需要时打开大屏审阅。
2. 在谱面时间轴拖选一段，带前后文试听。
3. 展开 **收集训练示范（可选）**，选择 **只学采音／只学配置／采音和配置都学**。
4. 只有认可从前文接入的第一步时，才勾选「同时学习如何接入前文」。然后点 **收为训练示范**。
5. 已收集的范围显示在下面。点击可定位，点「移出」可取消这段示范；不用删除原谱面。
6. 点 **加入下次训练来源**，把这些范围整理到统一的「人工确认示范库」。后续修改收集范围，再点「更新示范库」。

普通「好」评价、整谱好评和 A/B 胜出只记录意见，**不会自动收入训练示范**。不要因为 A 比 B 好就整张加入训练；可以只收集 A 中确实认可的几段。

## 5. 已保存的内容在哪里看

- **当前谱面的意见和素材片段标注**：预览右侧「已保存的标注」，点击范围回看。
- **当前生成任务收集的好片段**：「收集训练示范」下方的范围列表，含学习内容与移出按钮。
- **候选库的确认进度**：目录的「你的学习决定」列，以及「查看已保存的决定」筛选。可分别找出整张学习、部分学习、整张不学习；重新打开谱面可查看保存范围。
- **已经整理或导入的示范**：「训练素材」中的「人工确认示范库」。它是一个合并来源，不会为每个片段新增一张数据集卡片。打开后仍可预览完整谱面及标注。

## 6. 导出已审核的亮眼片段

### 从训练素材导出

在「训练素材」勾选来源，找到顶部 **搬到其他设备：导入／导出已确认片段**，点 **导出已确认片段**。普通来源只导出明确圈选并保存为「好」的范围；候选库只导出有效确认；已发布示范库按其中的学习范围导出。未确认部分、问题标记和不确定范围不作为示范导出。

### 从生成任务直接导出

在预览右侧「收集训练示范」中，先收集认可的范围，再点 **导出本任务已确认片段**。不必先加入训练来源。

后台打包完成后，点 **下载片段包**。ZIP 中包含：

- 对应的完整谱面和音频，保留 BPM、变速、偏移及原始写法；
- 确认范围、采音／配置学习选择，以及已确认的前文接入；
- 用于核对文件是否一致的校验信息。

**导出的不是裁断后的迷你谱面。** 完整前文保留为上下文，只有确认范围参与学习；不会把未确认部分删掉后当成休止，也不会把片段末尾当成歌曲结束。正常休止应连同两端的音符一起确认，独立空白不能单独提供普通事件目标。

打包在后台进行，可以继续浏览；不包含模型检查点、MERT 缓存或训练日志。音频会占用主要体积。

## 7. 导入片段包并用于后续训练

1. 在「训练素材 → 搬到其他设备：导入／导出已确认片段」点 **导入片段包…**，选择刚才下载的 ZIP。
2. 等待核对。界面显示歌曲、等级和片段数量；展开歌曲可看具体范围与学习内容。
3. 点 **确认导入示范库**。系统核对文件并保存一份独立素材，原资料不会被覆盖。
4. 点 **浏览示范库**，试听导入后的内容和前后文。重复导入同一包不会重复增加学习权重；不同包中同一谱面的确认会合并，重叠处使用后导入的选择。
5. 确定用于下一阶段时，点 **加入下次训练来源**。这只勾选示范库。
6. 检查其他训练来源，再点 **应用勾选的数据集**；最后去「训练模型」选择新输出目录进行 **finetune**，保持 **人工反馈学习 → 使用已保存的质量标注和训练示范** 开启。

单独导入、登记或勾选不会启动训练。新增范围不要混入当前的严格 resume；等当前任务结束，再从保留的检查点开始新的微调阶段。

如果只想学习候选库中确认的片段，不要同时勾选它对应的原普通训练集，否则原普通来源仍会提供整谱内容。少量好片段通常与原有可靠训练集一起使用。

## 8. 一个完整例子

某首生成谱的前半段混乱，40–52 秒的一段滑条接拍写得很好：

1. 只圈选 40–52 秒，带前后文听完整个手法。
2. 如果踩音和配置都认可，选择「采音和配置都学」，点「收为训练示范」。前面的混乱范围不用加入。
3. 如果只有配置好、采音取舍不满意，就改选「只学配置」。
4. 加入示范库，或者导出片段包换设备继续整理。
5. 下一阶段把可靠训练集与示范库一起用于 finetune，观察模型后续实际生成是否改善。

标注让训练更集中地学习你认可的写法，不会直接修改当前模型，也不能单凭标注数量保证谱面质量。判断效果仍要看后续生成与实际试听。

## 9. 自动质检与人工示范一起使用

自动体检先排查问题，再从通过检查的片段挑选值得多学的写法。

1. **先排除或降权问题内容**：屏蔽硬物理无理（含回溯引发冲突的长按／滑条起点）、未对齐节拍网格的散乱落点与异常高频连打，排除或局部屏蔽音画错位与速度漂移；同时按同难度档位，将手顺最别扭的一小部分片段做配置软降权（默认最低 5% 降权为 0.25）。
2. **再适度加强好片段**。默认从踩音贴合、手顺达标的乐句中选择好段，采音权重 1.20 倍，配置权重 1.35 倍。

在「训练素材」打开一份库，可检查当前库。在素材列表或训练页，可以检查勾选的来源。按钮下方显示本次检查对象。

1. 选择正式体检或先抽查 20 张。训练页的「自动质检张数」填 0 会检查所有符合范围的谱面，填正数则只生成抽查结果。
2. 完成后在看板查看正式结果或抽查结果，筛选问题谱、好段或待核对项。打开谱面后，点击侧栏片段定位，再点「循环试听这一段」。组合清单供查看，人工标注请回对应原库保存。
3. 开始新训练或微调时，在「素材自动体检与人工反馈学习」开启质量标注学习，并按需将「自动分段质检策略」设为「自动采用已有体检结果」或「强制要求使用自动体检结果」。

正式结果保存在清单旁的 `auto_quality_annotations.json`，抽查使用带 `preview` 的独立文件。组合清单优先使用与自身版本匹配的正式结果，其次使用从各来源继承的有效正式标注。人工片段意见覆盖对应区间，恢复被自动整谱排除的谱面需在素材目录明确保存整谱标签。示范库与候选库继续按人工确认范围学习。旧人工记录缺少保存范围信息时，仍沿用原解释。

续训沿用检查点记录的规则。启用过自动质检的检查点会核对标注指纹，修改质检结果后应选择新目录微调。新审计记录包含音频摘要，用于识别同路径下替换过的音频。
