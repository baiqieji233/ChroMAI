# 候选库：从更多谱面中挑选值得学习的片段

候选库用于审阅尚未收入正式训练集的资料。原谱、原音频和原数据集标注保持原样；候选库有独立标注，未确认范围不参与学习。它不会改变正在运行的训练。

按界面逐步操作、训练集与生成结果的区别，以及片段包的导入导出，见[审阅与标注操作指南](COMPOSER_V2_ANNOTATION_GUIDE_ZH.md)。

## 操作顺序

1. 在主界面「训练素材」登记并预处理资料，点击数据集卡片上的「建立待审候选库」。后台自动使用最多 4 个独立 CPU 检查进程，每进程一个计算线程，不使用 GPU，也不准备 MERT 缓存。
2. 打开候选库，查看错误、待核对、低风险及已有资料排除项。「低风险」只表示扫描未找到问题，仍需试听。
3. 点击「继续审阅」，完整谱面会定位到建议范围并带前后文。可在谱面时间轴拖动选区，或回到整首查看。
4. 听完选择「采音和配置都学」「只学采音」「只学配置」或「暂不学习」。保存后可自动定位下一段，也可以撤销上一次操作。
5. 若连同前文试听后也确认第一组音符接得合理，可勾选学习进入本段的第一步。它只在学习采音时生效。
6. 勾选候选库加入下次训练来源。界面会启用质量标注；点击「估算所选来源的学习份额」，可分别查看各来源提供的采音和配置学习内容。估算在后台运行，显示阶段和进度，也可以取消；页面仍能继续浏览。相同资料会复用结果，修改资料或标注后重新计算。这是按加权音符头估算的份额，不是质量评分或实际 loss 占比。
7. 使用新输出目录进行 finetune。训练来源会冻结成快照，只有有效确认范围含有音符目标的槽位进入快照。原来的正式资料和重复加权保持。

候选范围保留完整前文作上下文。确认一段不会把相邻未审阅部分变成休止答案，也不会把片段末尾当歌曲结束。休止本身可以学习，但应连同两端音符确认，独立空白没有普通事件目标。

## 怎样理解检查结果

首次检查会依次核对已有资料、源谱与音频、原有标注，再检查各张谱面。页面每两秒更新阶段、数量和本阶段剩余时间；估时来自已经完成的实际工作，会随谱面复杂度变化。刷新页面也能继续查看。

检查会读取音频、核对偏移并运行整谱冲突分析，首次检查比浏览目录耗时更长。重新扫描会复用未变谱面和音频的缓存；中断后也能继续复用已经完成的单谱检查。未全部完成前不能保存正向评价，避免把未核对的内容当作学习答案。需要降低后台 CPU 使用量时，可在命令行使用 `--workers 1` 串行检查。

- **错误**：缺文件、无法解析、缺等级、音频无法读取等明确的数据问题。先修正源资料，再同步。
- **待核对**：可能偏移、漂移、原生冲突、近似已有谱等提示。它们不自动说明谱面差，确认后仍可学习。
- **低风险**：没有自动发现问题，不代表模型应直接学习整首。

正常舍音、休止、重复、16/24分混用，以及某种滑条很少，都不作为自动淘汰理由。声学偏移只是建议，不会自动修改 `&first`；扫描阈值仍来自小规模试点，不能代替人工核对。

同文件同槽位，以及同音频的完全相同谱面，会标为已有资料。近似配置只提示待审；不会因为标题相同或某种写法少见就自动删除。候选库与正式资料同时选中时，正式资料优先，不会被候选的零监督设置覆盖。

## 修改源资料之后

源谱、音频或源清单变化后，旧确认会显示失效。点击「重新扫描／同步」，查看新内容后重新确认。旧标注会留档，不能套用到不同内容；旧试听页面也不能给换过的音频保存评价。

若后台仍在运行旧版本，界面会提示重启后启用候选库。先保留当前训练，在它结束后再重启后台即可。新增资料与标注不应直接混入严格 resume；它们用于下一阶段的新目录微调。
