# 完整谱面审阅与反馈

「训练素材」页顶部设有「训练集谱面预览」。点击「浏览训练集」，打开数据集，再点击歌曲旁的「预览与标注」，即可查看对应难度槽的游戏画面和音符时间轴。可在预览中切换「上一张／下一张」，沿用目录的搜索和排序，跨页时自动载入相邻页面；「回到目录」会定位到当前谱面。

训练素材和生成结果复用同一个播放器，分别保留各自的预览来源。圈选训练素材后，评价直接保存到该素材的质量标注；右栏「已保存的标注」可查看并定位。详细权重与修正版设置收在素材详情的高级选项中。

生成后先试听完整成品。主播放器只列出实际导出的完整版本；「打开大屏审阅」的主要区域上方显示游戏画面，下方显示音符时间轴。右侧工具栏集中放置范围试听、记录意见、版本对比和原文，展开更多内容时独立滚动，不会把主预览推走。可以收起工具栏扩大主区域；窄屏改为上下排列。按 Escape 或「收起大屏」即可返回。导出按钮始终对应正在预览的版本。

大屏中的游戏画面默认接近一半窗口高度，较矮的屏幕会适当缩小，给时间轴留出空间。可上下拖动画面下方的分隔条调整画面大小；双击分隔条恢复默认。时间轴行高也随屏幕高度调整，选择位置会按实际尺寸计算。调整尺寸、收放工具栏均不会重新载入播放器。

预览默认不再额外限制30帧，跟随浏览器在当前显示器上的刷新节奏。320Hz显示器可以使用相应的高刷新率；实际帧率仍取决于浏览器、渲染负载和设备性能。暂停或切到后台时的低帧率不代表播放时被限速。

谱面时间轴自动载入：1–8 键各占一行，Touch 单独一行。音头区分 Tap、Hold、Slide 和 Touch，长按显示持续区间，Slide 显示等待段及各段起终键与时间；这些线条是时间示意，不冒充原生轨迹。指向音头可查看原文、准确位置和时值；未完整识别的写法保留提示。

默认显示约 16 秒以便看清音符。点击音头选择同拍组合，并包含持续动作尾部；拖动选择谱面区间，边界参考实际音符起点，不按固定四拍分段。选好后，播放器同步定位到选区起点；空白处点击则直接定位。

普通滚轮用于前后移动时间，保持缩放比例；全曲概览和下方进度条也会同步改变播放器位置。播放／暂停状态保持不变，手动定位会退出区间循环。默认开启「跟随播放」，播放器内拖动进度条时，音符时间轴也会定位到对应位置。「放大」「缩小」「全曲」「详细视图」只改变显示尺度，不改变播放位置或生成文件。

波形默认关闭，只有勾选「显示波形背景」时才准备音频缓存，作为弱背景帮助对齐。主要选择对象始终是谱面音符。所选范围会显示秒数、拍位、音符数和同拍组数，原文可在只读详情中核对；精确秒数输入收在高级范围设置内。

「循环试听这一段」默认带上前后各 4 秒，帮助判断进入和退出。页面分别显示你正在评价的范围和实际试听范围；前后文不会扩大保存的评价。取消前后文只听选区。「清除选择」停止区间循环但不打断正常播放；暂停会停止循环。

只有一张谱面时，直接记录「好」「有问题」或「不确定」，原因可选采音、配置或手感；未选区时评价整张。已有另一张同音频完整谱面时，展开「比较另一张」选择版本 A/B；两个版本共用范围，切换保留位置和播放状态。当前预览版本有明确标识，单谱意见记录到它对应的文件。

保存后，右栏「已保存的标注」列出评价与范围，点击即可定位。训练示范另列在「收集训练示范」中，标明学习分项；训练页只显示一个「人工确认示范库」来源及汇总数量。三处各自对应评价、示范选择和训练来源。

生成设置里的「生成时自动尝试的写法数」是内部选优预算，试排后只保留成品。需要人工比较两张完整版本，请把「生成张数」设为 2 或更多。这里不会自动产生对照谱面。

「同时生成数」控制这批完整谱面的并行数量：例如生成8张、同时生成数设为2，就同时运行两张，完成后自动补上下一张。默认1逐张生成，共用一次模型载入；并行时每个进程各载入一次模型，复用已准备的音频特征。可从2开始尝试，显存占用随并行数增加。每张使用独立随机种子和输出目录；单张失败会记录日志，其余继续生成，最终仍在同一批次预览里查看。

使用CPU生成时，展开「高级生成设置」调整「CPU计算线程」。默认0自动分配，每个生成进程最多8线程；同时生成多张时会按可用CPU分摊。手动值表示每张的线程数，例如同时生成2张、每张4线程，合计约8个算子线程。单张谱面仍按先后顺序续写，矩阵计算由这些线程协作完成。自动模式下使用GPU生成时保持2个CPU线程。实际线程分配写入日志与生成报告。

普通意见独立保存并关联文件版本与音频哈希，不会自动改写谱面、训练标签或启动训练。

右侧「收集训练示范（可选）」用于把其中确实值得学的部分交给后续微调：先在时间轴拖选，带前后文试听，再选择「只学采音」「只学配置」或「采音和配置都学」，点击「收为训练示范」。列表中的范围可以点击定位，也可以移出。普通好评、整谱好评，以及 A/B 中相对更好的版本都不会自动成为训练示范。

积累几个片段后，点击「加入下次训练来源」。所有歌曲、所有任务的示范合并成一个「人工确认示范库」，与原训练集一起勾选；训练页显示谱面数和已确认片段数，不为每段新增卡片或参数。Composer v2 的「人工反馈学习 → 使用已保存的质量标注和训练示范」默认开启。使用新目录 finetune，原检查点保留。移出片段后点击「更新示范库」，让改动用于下次训练；历史快照供旧检查点复现使用。

校准素材保留完整谱面作为上下文，只有明确确认的范围参与对应分项的损失。不会删除问题音符后把它们的位置学成休止，也不会把片段末尾学成整曲结束；跨越未确认区域的第一步跳转不作为采音答案。未确认的整谱统计和参考片段也不会被当成可靠编排条件。范围边缘不足以确认完整计数的强度曲线区间不参与监督。

问题标记有助于排除已收集范围里的错误，但没有告诉模型「正确的应该怎么写」。本版没有给 Composer v2 接入基于这些 A/B 记录的偏好损失；偏好记录可供今后研究，不能把仅有反例说成已经实现了纠错学习。少量片段也不能代替原有训练集，是否改善仍需比较微调前后的实际生成。
