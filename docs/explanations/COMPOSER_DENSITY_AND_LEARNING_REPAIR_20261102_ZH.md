# 极端物量与学习效率：本轮修复说明

这次先停止了 v44 训练，保留原检查点，并把完整点备份到 `.scratch/density_audit_20261102/parent_v44/`。工作重点是解释并修复最新输出的密度失控，同时检查“训练 loss 在降，配置却没有变好”的原因。没有把所有问题都归为训练不足，也没有为了让曲线好看而整体缩小 loss。

## 这次为什么会突然写出两千多个音符

最新任务 `38281e0cf178` 在 129.18 秒内生成了 1633 个事件、2146 个音符。界面保存的密度是 0.329，但自动整曲风格最终给模型的密度是 **0.984375**。项目把密度归一化到每秒 16 个音符：这个值相当于每秒 **15.75** 个，实际输出每秒 **16.61** 个。模型确实收到了一个极高的物量要求。

旧风格预测器把每个数值分成 129 档，并对每个字段分别抽样。即使主体分布合理，也可能抽中残余的小概率极端档。原输出使用 step 2920；保留下来的近邻点为 step 3000。后者的只读探针中，密度均值为 0.3255、99% 分位为 0.5，0.984375 档的边缘概率约 0.00137%。这不能冒充对原 2920 权重的精确复现，但说明不必整个模型都偏向高密度，也可能产生灾难性的一次抽样。

强度曲线没有纠正它，原因有两层：

- 曲线记录的是另一套条件（等级 14.8、密度 0.435），生成实际使用等级 13.7 和自动条件。旧逻辑只把“编辑后的曲线／参考曲线”的比值乘到当前预测上，本次平均倍率约 0.9987，几乎没有降低当前密度。
- 原来给所有候选拍点加一个相同的密度偏置，经过概率归一化后会抵消。它没有正确表达“整体密度降低，就应该更倾向较远的下一音”。

## 已经怎样修改

### 整体风格保留多种选择，连续数值不再逐字段抽极端档

仍然先选择一种整体写法；在选中的写法内，密度、峰值和各类比例使用预测分布的均值。不同写法仍可以有不同的倾向，用户明确锁定的值继续优先。没有增加硬性的密度上限，也没有固定曲风模板。

生成报告现在记录所选写法、数值均值、标准差、分位数和尾部概率；界面显示真正生效的密度与峰值，避免只看到输入快照。

### 新版风格学习目标认识“差一点”和“差很远”

旧的分类目标并不知道 0.30→0.31 比 0.30→0.98 更接近。新版 `masked_ordered_joint_v2` 保留原来的联合概率学习，再加入数值分布距离（CRPS）。这不是重新缩放总 loss；它为连续控制量提供了原先没有的距离信息。

同时，按一张谱面拥有多少训练窗口做权重修正。原先批内虽然按谱面去重，但长谱、密谱跨更多批次出现，仍反复训练整体风格。现在一轮中每张谱面在这个目标上的总贡献相同。编码仍按批内不同谱面计算一次，没有重复跑音频编码器。

此目标有新版本标记，不能默默当成旧合同直接续训。旧版明确 resume 时保留旧目标；新阶段采用新版。

### 曲线真正改变下一音的间距概率

曲线的保存条件与实际条件不同时，使用曲线保存的绝对物量目标重新对齐。条件相同、曲线未编辑时继续保持原来的不干预行为。

选时不再只加某个时刻的偏置，而是比较原计划与新计划在“从当前位置到候选位置”之间积累的出音强度。密度降低时，较远的候选能真正增加相对概率；NOTE 与 WAIT/EOS 的概率也按相同区间更新。计算使用缓存积分，不新增模型前向，不增加硬性重复惩罚。显式休止区和既有物理守卫保留。

## loss 是否有严重错误

有需要修正的学习设计，也有必须如实保留的反证。

v44 第 4→5 轮，训练总 loss 从 7.166 降到 7.061，但验证配置 loss 从 4.540 升到 4.777，其中细节从 1.600 升到 1.893；选时却继续改善。这说明确有局部倒退，不能只看总数。

但本轮没有查出“短句目标把细节梯度全部抵消”的错误：

- 相位与细节的差量项、音符类型预算重分配和两级短句边际，与独立公式及梯度对照一致。
- 真实 batch 中，短句目标与普通配置目标在细节循环网络的代表权重 `detail_cell.weight_ih` 上梯度范数几乎相同。
- 物量计划与配置目标对 `audio_input[0].weight` 的梯度规模接近；该批次方向正相关，不能宣称两者必然互相抵消。探针只取代表参数，不是全模块范数；接近零的残余梯度余弦不能用来证明实质冲突。

总 loss 中也包含不同量纲的目标。例如第 5 轮约为：选时 0.636、配置 3.774、加权物量计划 2.259，另加风格及辅助项。物量计划使用 Poisson 计数损失，其最优值本来就不总是零。真实 batch 的原始计划损失为 19.606，其中按目标计算的固定下界约为 8.311。**只有一部分是固定项，不能把剩余误差都解释成底噪。**

现在额外显示“主预测损失（采音与配置）”“物量计划加权值”“物量计划固定下界／超额误差”“风格数值分布误差”。原总目标没有通过扣常数或乘小系数来美化。

## 学习率与实际学习验证

从同一个 step 3000 完整点出发，继承同一 Adam 状态和随机状态，在相同四张真实训练谱上重复 40 次更新：0.0005 的训练 loss 降得更快，但独立开发样本的细节损失从 2.499 升到 3.866；0.0002 为 3.193。两者都出现小样本过拟合，因此它不是“0.0002 是全量最优学习率”的证明；它说明更快降低训练 loss 不一定对应更好的配置学习。

新阶段采用较温和的 0.0002，并另外执行按全量数据顺序的短程更新，在同一开发集上比较核心预测项。这个全量顺序验证的结果会记录在验收补充中，不拿重复四张谱的训练成绩冒充泛化提升。
