# WebUI 操作流程整理（2026-10-12）

本轮针对当前架构的使用界面进行整理，不需要重新训练模型。现有 WebUI HTTP 接口、CLI 参数和原有 324 个控件/状态 ID 均保留；新增的是界面分组、导航、摘要与日志工具。

修改前的源码快照：`backups/webui_workflow_20261012_2ef3bd3/source_before_ui.zip`。前一版发布标签 `legacy-compatible-2026-10-12` 保持不动。

## 训练页

主流程分为三步：

1. **选择训练素材**：选择本次训练来源并检查。导入、登记和预处理新素材放在单独区域；多训练集的勾选仍在“训练素材”页完成。
2. **选择训练起点**：从头训练、从断点继续、已有模型加强训练各有用途说明。从头训练时收起不需要的 checkpoint 输入。
3. **设置训练与输出**：直接调整轮数、学习率、batch、梯度累积、设备与输出目录。

新增“快速设置运行方式”：

- 短跑检查设置为 1 轮、最多 32 个训练 batch、2 个验证 batch，仅修改参数，不启动任务。
- 完整训练清除 batch 上限，保留已填写的轮数；界面会提醒仍需设置本次轮数。
- 批次组合提供 8×4、4×8、16×2，不改学习率与模型结构，也不保证显存一定足够。

高级设置按用途折叠：数据筛选与采样倾向、质量加权与反例、模型结构与窗口布局、条件/正则化/规划学习、性能/保存/复现、独立验证集。金标切分放在可选验证工具内，不再占据必经流程。

运行前摘要显示素材、起点、轮数、短跑限制、学习率、批次组合、验证方式、质量训练、采样倍率和输出目录。

## 生成页

按歌曲与模型、等级与偏好、节拍时间、局部强弱、采样方式、无理处理、输出组织参数。

- 曲线指导强度、曲线模式、自动跟随与收尾处理放在同一组。
- 温度、Top-p、重复惩罚和 token 预算与难度/曲线分开。
- 无理检测的总开关、处理预设与修复模式先显示；类别策略、单 note 编辑、重试和前置长音回溯收进高级项。
- 细碎音倾向与局部采音对齐独立分组，继续按 checkpoint 能力开放。
- 验收统计、输出元数据与重置工具各有自己的折叠区域。
- 生成前摘要显示歌曲、模型、等级、候选数、种子、时间轴、曲线与无理处理方式。

“恢复生成默认值”保留导入路径；“清空导入路径与生成参数”清除歌曲、模型及报告路径，恢复生成参数和默认输出路径。两者都保留训练设置。

## 参数调整与状态修正

- 顶部可按中文名称、英文控件名或参数名搜索，点击结果会展开所在区域并定位。可一次展开或收起高级设置。
- 折叠不改变参数值或其是否生效。训练页显示高级设置与页面初始值不同的数量，其中包含从模型继承的值。
- 手动学习率不会因为切换训练方式被重置；手动设置的加强训练上下文 token 上限不会被模型检查覆盖。
- 不支持局部采音头的模型会禁用相应控件，但保留用户填写的数值；请求仍按原能力规则提交 0。
- 续训和加强训练在开始前自动检查 checkpoint，再组装请求。断点续训继承模型合同；检查失败不会提交训练。
- 训练检查与任务提交期间防止连续点击重复发起请求；检查失败后恢复按钮，允许修正再试。
- 事件模型的一键预处理可先检查 checkpoint 本身，再由后端在预处理后验证完整数据合同。旧固定帧模型的续训/加强训练要求先预处理，再开始训练，避免缺失清单产生误报。
- 修复清空操作只改 textarea 初始文本、没有真正清空用户编辑值的问题。
- 删除了“默认 event_v1”“验证集是必经步骤”“更多 epoch 通常比 best 更好”等误导性引导；修正模型容量、音频贴合指标和难度槽位的部分说明。

## 任务与日志

- 可以选择查看其他任务，刷新素材不再强行抢回正在运行的任务。
- 同一任务只保留一条轮询链，切换查看对象保留原任务结束回调。
- 状态使用中文；训练进度继续读取后端实际轮数，没有数据时不编造百分比。
- 支持全部/错误/警告/关键事件筛选、关键词搜索、换行、复制显示内容、下载完整日志。
- 向上滚动会暂停自动跟随，轮询保留滚动位置；勾选“跟随最新”回到末尾。
- 可以切换全宽日志视图，完整历史日志入口在训练和生成时都可访问。
- 页面日志仍受后端最近日志缓冲范围限制；需要完整历史时使用下载。
