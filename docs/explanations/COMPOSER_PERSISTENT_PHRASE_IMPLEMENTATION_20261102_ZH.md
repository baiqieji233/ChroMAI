# 完整短句学习：改动原因、实现与操作

2026-11-02。模型仍采用 `event_set_stream_v1` 流式生成。本文是本轮新合同，历史v40及更早文档中的状态不代表新版。

## 为什么改

v40已经能够根据音频选时，局部错误比早期少。但固定歌曲抽检中，节奏相似并没有稳定带来完整配置的呼应；用户也指出，很多段落停留在保守的四分、八分写法。四分和八分本身不是错，更密也不自动更好。

这次不强迫模型增加细分，而是让它学习“这一小段准备怎么写、怎样接下一段”。另一个问题是时值、修饰符和路径在许多不同配置下分别学习，容易重复消耗训练样本。本轮把这些知识共享起来。

## 实际做了什么

1. **训练按完整短句组织。** 使用音乐已有的结构边界，不贴主歌/副歌标签。相邻短句可以同处一个连续训练块，各句仍有独立选择，避免短句太短时反复编码128事件历史。每块附带后面2个事件作为接缝监督；重叠目标分摊权重，不多算一份loss。默认块上限64事件；被上限切开的句子明确不算完整短句目标。数据集保留完整句覆盖统计，训练日志报告实际参与的完整句组数。
2. **一种写法贯穿整句。** 默认4种可学习的内部写法选择。训练先累计每种写法对整句的解释，再合并这些选择；不是每颗音符分别挑最容易的方案。推理同一音乐短句保持同一个选择，但实际音乐、已写配置和持续占用仍能改变每一步输出，所以没有硬性照抄指令。
3. **从当前前缀预测未来关系。** 小型训练头预测随后两个NOTE的真实落点集合、集合变化、间隔和持续动作类型。它读取当前前缀，不读取真谱下一音符时刻及派生占用。这些未来标签只参与loss。
4. **参考旧句允许变奏或新写。** 已提交参考段的真实按钮集合经旋转/镜像形成可选的软参考，并有不使用参考的选项。不会强制“相似音乐必须镜像”，也不把旋转等同相同手感。Slide细节仍由精确目录和当前状态决定，不做未经验证的字符串镜像。
5. **不同配置共享细节知识。** 修饰符、精确时值文本、路径和相对终点共同构成共享候选表示。仍在原合法目录中计算联合概率，保留准确解码；没有把特殊时值粗略量化，也没有把几个因素当成互不相关的独立答案。
6. **稳定时间特征尺度。** 新阶段持续区间读取将两个原始秒数特征改为有符号log1p表示，保留音频区间信息与原本评分，不靠降低细节loss权重改善显示数字。它能消除明显的时间尺度差异，但不能据此宣布细节loss波动的唯一根因已解决。
7. **生成、恢复和回退共用合同。** 已提交事件保存其短句选择；候选失败不会写入正式前缀。撤回Hold/Slide、回放前缀或恢复采样时，只根据实际保留的事件重建选择。
8. **改善效率的同时补齐观测。** 关系标签按歌曲缓存，不逐样本扫描全曲；长短样本在同一歌曲内有界分桶，减少padding。音频和历史主干只运行一次，模式轴只在小输出头上展开。细节候选训练每loss计算一次，生成只计算当前配置的候选。新增有效目标预算/秒，避免用长度已经变化的“短句/秒”误比较速度。

## 最重要的输入边界

短句归属与历史窗口均按**已经到达的当前时刻**确定，不能用真谱下一音符的位置决定该截取哪段历史。训练、正式生成、恢复采样使用同一规则。动作在选好下一拍后，仍可读取该拍的音乐与真实持续占用。

未来音频是已知输入，可以读取；未来真谱只能是训练答案。整句模式的先验来自当前句音乐及已经完成的参考，不能用整句真实答案选择模式后，再把选择假装成输入。

接缝目标另有一个更长过去上下文的辅助视图；主句核心的历史窗口必须与推理一致。超长句切片不参与完整句模式目标，不能把局部近似称为完整句学习。

## 主界面怎么设置

选择“整拍集合连续生成”，新建训练使用fresh及新目录。以下是新字段；主界面普通使用保留自动，高级项分在短句组织和细节学习中。

| 控件 | 新阶段默认 | 含义 |
|---|---|---|
| 训练窗口 | 自动 → 完整短句 | 按音乐短句组织学习；旧分块用于旧合同 |
| 短句最多事件数 | 64 | 限制单次训练块目标长度；不是生成最多64颗或强制换写法 |
| 短句接缝事件数 | 2 | 额外学习训练块之后的衔接，重叠目标分摊权重 |
| 整句写法 | 自动 → 持续写法 | 同一选择解释整句，而不是逐颗换方案 |
| 短句写法数量 | 4 | 内部可学习选择数量，不是固定模板数或生成分支数 |
| 短句关系学习权重 | 0.1 | 当前前缀对后续关系的训练监督，不是生成重复惩罚 |
| 细节表示 | 自动 → 共享构件 | 不同配置共享精确时值、修饰符及路径知识 |
| 时长特征 | 自动 → 对数时间 | 缩小原始秒数尺度差异，保留精确编解码 |
| 短句写法温度（生成） | 1 | 控制每句选择哪种写法的随机性；0选择最高分。它独立于音符动作温度 |

新建训练的学习率默认0.0005、变化方式恒定、预热0步，轮数50。批大小要按模型规模和实测显存设置；继续使用BF16、预取2、样本线程1、CPU线程2作为本机起点。

新版一个batch元素是连续训练块，可以包含多个完整短句。“短段展开”16作为块的目标起点：只有已积累足够事件并进入下一音乐句时才开始新块；事件上限仍控制最长块。不会为了凑数把四分写成十六分。

旧检查点按旧策略生成与续训；新能力需要新训练阶段。主界面会检查后端是否支持新字段，重启服务后才能使用新合同。生成仍默认单分支，不自动开启昂贵的多候选搜索。

## loss现在表示什么

总目标仍包含选时、配置、密度计划、短句辅助和恢复监督。配置项改成完整可信短句上的模式加权目标，替代原配置项，不再叠加第二份配置交叉熵。碎片和不具备完整可信对应的恢复样本使用局部混合；不可信配置仍屏蔽。

`shape_loss + phase_loss + detail_loss`保留为基础输出头的诊断分解。新版有：

`configuration_loss = shape_loss + phase_loss + detail_loss + phrase_configuration_adjustment`

其中adjustment是替换差值，不是额外罚分。不要直接拿新版总loss和v40数字比较好坏。应比较同一合同下的验证曲线、细节分量、模式使用情况，以及固定歌曲的实际产出。

## 关于保守节奏

静态检查没有发现当前选时存在top-p剪枝或粗网格温度失效。v40固定评估使用每首真谱导出的条件，不能把它的保守写法归咎于普通生成的默认风格。

新增报告分别统计实际起音相位和相邻音符间隔，并按同一歌曲的音乐短句对照真谱。这样可以区分“最后一颗落在整数拍”和“整段都只写四分”，也不会以增加密度作为质量成功标准。

## 本轮边界与后续

本轮实现核心的完整短句、持续选择、多步关系及共享细节；没有同时引入重型双向教师、自动全曲风格分布模型或固定微动机队列。这些保留为后续替代路线，避免多个新控制器互相争夺输出。
