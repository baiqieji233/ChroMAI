# Composer v2 强度曲线与重新训练

## 这次解决什么

原模型只有整首歌的等级、Radar 和 Style 条件，没有一份可以编辑的局部疏密安排。生成时一旦进入密集或稀疏的写法，后面的音乐不一定能及时推动它换挡。这次让模型从真实谱面学习整首歌的疏密曲线，再把曲线作为写谱时的参考。

曲线表示的是**出音和物量，不是难度定数或完整手感**。每秒四个单押和每秒两次双押物量相同，写法却不同，因此内部区分两项：

- 出音频率：每秒有多少个不同的落点。同一时刻的双押只算一次。
- 同拍额外物量：这些落点除了第一颗音符以外，还有多少颗音符。二者相加，就是每秒音符数。

Slide 算起始音符，Hold 算长按头，不把轨迹判定点或持续时间误算成大量新音符。持续占手和操作难度仍由现有模型与物理检查负责。

## 训练与生成如何对齐

按音频时间划分固定两秒的区间，最后一段按实际剩余时间计数。歌曲开头、尾部以及音乐仍在响但谱师没有写音符的区间也参与学习，零计数就是正常监督，没有“有声音必须写音符”的规则。

小预测头只读取音乐与等级，不读取由真实谱面统计出来的 Radar / Style，避免自动预测偷看本来未知的物量答案。它复用已有的全曲音频编码；编码帧插值到曲线区间，不重新运行 MERT、不新增 Transformer。用计数损失学习区间内的事件数和额外物量，计算时包含真实区间时长，避免不同歌长、变 BPM 和尾部不足两秒造成单位错误。

训练约一半样本使用预测曲线，另一半使用经过平滑和轻微扰动的真实曲线。这样既能学会参考用户的疏密安排，也必须适应自己预测不够准的情况。验证一律使用自动预测曲线，不把真实谱面的曲线当作生成时已知的答案。

解码器读取当前位置及后面两秒、四秒的曲线作为条件，帮助决定接下来怎样安排。这里没有第二套采音概率，也不按曲线强制补音、封禁留白、缩短音符或增加多押。自动模式的预测头通过计数目标学习；谱面损失不通过曲线值反向把这些数字改造成难以解释的隐藏暗号。

## 在主界面使用

训练侧「模型与上下文 → 学习强度曲线」保持 **自动：新训练／微调启用，续训继承**。这次要从零训练，应使用新输出目录。旧检查点保留；旧模型直接生成时仍按原方式运行。想给旧模型增加此能力，需在新目录微调，不能通过旧合同的 resume 硬开。

生成侧展开「强度曲线：总体物量与疏密安排」：

1. 支持曲线的新模型，直接生成时已经自动使用预测曲线。
2. 「预测并编辑曲线」可以先预览。主图是每秒音符数，可选点、框选和拖动，或用数值输入精调。
3. 使用图上方「编辑内容」切换总体强度、出音频率与同拍物量。总体编辑会保留原来的同拍比例；导入导出位于「曲线文件」及上方按钮。
4. 修改后自动勾选「生成时使用当前编辑曲线」。影响强度 1 使用编辑值，0 回到模型自动值，中间值混合两者；它不是硬性物量预算。
5. 支持撤销、恢复自动曲线、导入和导出 JSON。生成时会核对音频身份及数值，避免把别首歌的曲线套进来。新预测在子进程执行，不占住 HTTP 处理线程。

曲线分支需要经过训练才可能有效。显示了曲线、概率发生变化，均不能直接证明谱面的音乐性提高。

## 最近修改的评估与调整

v6_finetuned_v4 前三轮训练 CE 从 0.15590 降到 0.14262、0.13254，自动条件验证 CE 从 0.15960 升到 0.16502、0.16839；拍内验证 CE 同时从 0.11088 升到 0.12064。相同验证路径连续变差是实际警讯，不能继续把训练 loss 下降当成生成改善。训练与验证的条件遮挡和样本权重也不完全相同，因此两者的绝对差值不能单独用来量化过拟合。

近期逐拍参考、低可信参考不挤掉真实历史、明确的拍内相位和瞬态包络，分别解决了真实的输入问题，这些改动保留。新曲线也不能代替这些能力。

另一个明确的问题是按正确答案改变 token 的权重：旧方案提高混合分音、长空隙和 EOS 的权重，再降低其他时间 token 的权重来保持总量。这虽然加强了部分练习，却同时改变了模型最优的概率标定；尤其生成要用时间概率采样时，不能把“多练习”直接等同于“概率更准确”。**新训练与新微调改回通常的逐 token 交叉熵，保留谱面质量权重、相位表示和纠错样本；旧合同 resume 继续原算法。**这项调整是针对已确认的目标差异，并不宣称已证明它独自导致了这次退化。

曲线学习的辅助损失单独记录，权重为 0.05。训练日志里的 `loss`、时间、配置和拍内 loss 继续表示谱面交叉熵，`objective_loss` 才是反向传播使用的总目标；`curve_loss` 和 `validation_curve_loss` 单列。检查点仍按自动条件下的验证交叉熵择优，避免新加一个容易下降的任务就看起来“进步很快”。

新增「验证无改善早停（轮）」默认 5，0 关闭。每隔多少轮保留检查点默认 5，可生成也可续训。它们减少训练后段明显退化时覆盖历史版本的风险，不能保证最优模型一定具备高质量音乐编排。

## 新一轮的建议

先用目前已审核的数据在新目录 fresh；模型宽度 384、8 层、前馈宽度 1536，Dropout 可先用 0.15；学习率 0.0002、余弦下降、预热 200、最低比例 0.1；Batch size 8、梯度累积 8，以显存和实际吞吐为准。保留自动留出、正常休止与合理重复，曲线及节拍结构保持自动。

重新训练有机会让模型从一开始适应新的参考布局，避免微调时同时重学旧参考的含义。但从零训练不会自动修复数据覆盖不足，也不能保证超过旧模型。下一步应同时检查自动曲线是否合理、验证 CE 是否稳定，以及自由生成中的采音、休止、配置衔接；不能只看曲线拟合或训练 CE。

新训练默认验证最大批数为 0，即完整开发集。此前的32批预算只覆盖其中一部分，连续变差依然是警讯，但不能把这部分验证结果冒充全开发集结论。曲线验证另记录事件率与额外物量率的每秒绝对误差。


## 与独立协作者的复核

已通过 Antigravity 进行了两轮只读复核。双方认可复用全曲编码、事件率与额外物量率分开学习、自动路径参与训练、验证不读取真实曲线的最小方案。采纳了预测头只看音乐与等级、末尾小区间按实际时长加权平滑等建议；保留逐拍参考证据和错误前文恢复，以免为简化结构而丢掉已有能力。

第一轮曾提出相位词向量会受到额外19倍冲击；真实检查点测量不支持此结论：第1轮和第3轮的新增相位项 RMS 分别仅为原词向量的4.39%和7.99%，有效输入 RMS 从1.46797变到1.47595。第二轮已撤回该推断。其他“某模块导致过拟合”的说法仍需消融，不能冒充已经定位的单一原因。下一轮应看趋势与自由生成，不要求验证 loss 每一轮都严格单调下降。

实现验证已覆盖：曲线不读取真实验证答案、预测头不读取真实 Radar、增量解码与完整重算一致、编辑强度为0回到自动路径、真实训练保存／重载／续训、短尾箱数值，以及主界面预测子进程到编辑参数提交。52.62M参数模型的真实8样本 batch（4855个有效token）CUDA对照中，新增约7.05万参数，更新耗时约增加3.1%，显存峰值约5.03GB；这是固定batch测试，不是整轮吞吐或音乐质量验收。旧检查点只读使用，未启动正式训练。


## 音频定位与局部、多点编辑

生成页的曲线编辑器现在可以先「加载音频定位」，直接试听当前歌曲，不必先生成谱面或预测曲线。播放器、局部波形、可选的对数频谱和曲线共用秒时间轴。点击波形定位；可用0.5倍或0.75倍速度听细节，也可以循环当前视野。

「放大／缩小／全曲」、视野起点和跨度输入、全曲概览、下方滚动条控制可见时间段。Ctrl＋滚轮以鼠标所在时间缩放，Shift＋滚轮平移；播放时可以选择自动跟随。缩放只改变显示范围，不改变或重采样现有控制点。

默认「选点／空白处框选」：拖动控制点修改值，点击空白定位；在空白处拖框选中多个点，Ctrl点击可增减选择。「选中视野内所有点」便于处理整段。批量调整支持按比例、整体加减和统一设值，每次操作可一次撤销；总体强度调整保留各点原来的同拍比例。多选后拖动选中点会整体平移数值，保留点间差别。低于合法下限的值会归到0，同拍平均数下限为1。

单选时可以精确输入控制点的秒数与数值。双击曲线或「在播放位置加点」可新增插值点，删除操作至少保留一个点。手工新增的细密点会在生成实际查询时刻直接插值读取，不再先被压回两秒网格；自动预测与训练分辨率保持原样。能精确表达控制意图不代表模型会逐个音符硬性服从，还需试听生成结果。

波形、频谱仅用于定位，不作为强制采音标签；素材按音频内容缓存，不运行MERT、不占用GPU。页面与后台都更新后才能使用新的定位接口；已有训练无需停止或重训。先导出尚未保存的编辑，再刷新页面；后台代码更新在下次启动WebUI时生效。
