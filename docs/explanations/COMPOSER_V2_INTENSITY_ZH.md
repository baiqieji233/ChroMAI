# ChroMAI · Composer v2 强度曲线与局部疏密编辑

## 作用与原理

仅依赖整首歌的等级、Radar 和 Style 条件时，模型缺乏一份可以局部编辑的疏密安排；一旦生成进入密集或稀疏写法，后续音乐不一定能及时推动它换挡。ChroMAI 在 Composer v2 中支持从真实谱面学习整首歌的疏密曲线，并在写谱时将其作为参考。

曲线表示的是**出音和物量，不是难度定数或完整手感**。每秒四个单押和每秒两次双押物量相同，写法却不同，因此内部区分两项：

- 出音频率：每秒有多少个不同的落点。同一时刻的双押只算一次。
- 同拍额外物量：这些落点除了第一颗音符以外，还有多少颗音符。二者相加，就是每秒音符数。

Slide 算起始音符，Hold 算长按头，不把轨迹判定点或持续时间误算成大量新音符。持续占手和操作难度仍由现有模型与物理检查负责。

## 训练与生成如何对齐

按音频时间划分固定两秒的区间，最后一段按实际剩余时间计数。歌曲开头、尾部以及音乐仍在响但谱师没有写音符的区间也参与学习，零计数就是正常监督，没有“有声音必须写音符”的规则。

小预测头只读取音乐与等级，不读取由真实谱面统计出来的 Radar / Style，避免自动预测偷看本来未知的物量答案。它复用已有的全曲音频编码；编码帧插值到曲线区间，不重新运行 MERT、不新增 Transformer。用计数损失学习区间内的事件数和额外物量，计算时包含真实区间时长，避免不同歌长、变 BPM 和尾部不足两秒造成单位错误。

训练约一半样本使用预测曲线，另一半使用经过平滑和轻微扰动的真实曲线。这样既能学会参考用户的疏密安排，也必须适应自己预测不够准的情况。验证一律使用自动预测曲线，不把真实谱面的曲线当作生成时已知的答案。

解码器读取当前位置及后面两秒、四秒的曲线作为条件，帮助决定接下来怎样安排。这里没有第二套采音概率，也不按曲线强制补音、封禁留白、缩短音符或增加多押。自动模式的预测头通过计数目标学习；谱面损失不通过曲线值反向把这些数字改造成难以解释的隐藏暗号。

## 在主界面使用

训练侧「模型与上下文 → 学习强度曲线」保持 **自动：新训练／微调启用，续训继承**。若要从零训练，应使用新输出目录。旧检查点保留；旧模型直接生成时仍按原方式运行。想给旧模型增加此能力，需在新目录微调，不能通过旧合同的 resume 硬开。

生成侧展开「强度曲线：总体物量与疏密安排」：

1. 支持曲线的新模型，直接生成时已经自动使用预测曲线。
2. 「预测并编辑曲线」可以先预览。主图是每秒音符数，可选点、框选和拖动，或用数值输入精调。
3. 使用图上方「编辑内容」切换总体强度、出音频率与同拍物量。总体编辑会保留原来的同拍比例；导入导出位于「曲线文件」及上方按钮。
4. 修改后自动勾选「生成时使用当前编辑曲线」。影响强度 1 使用编辑值，0 回到模型自动值，中间值混合两者；它不是硬性物量预算。
5. 支持撤销、恢复自动曲线、导入和导出 JSON。生成时会核对音频身份及数值，避免把别首歌的曲线套进来。新预测在子进程执行，不占住 HTTP 处理线程。

曲线分支需要经过训练才可能有效。显示了曲线、概率发生变化，均不能直接证明谱面的音乐性提高。

## 音频定位与局部、多点编辑

生成页的曲线编辑器支持先「加载音频定位」，直接试听当前歌曲，不必先生成谱面或预测曲线。播放器、局部波形、可选的对数频谱和曲线共用秒时间轴。点击波形定位；可用 0.5 倍或 0.75 倍速度听细节，也可以循环当前视野。

「放大／缩小／全曲」、视野起点和跨度输入、全曲概览、下方滚动条控制可见时间段。Ctrl＋滚轮以鼠标所在时间缩放，Shift＋滚轮平移；播放时可以选择自动跟随。缩放只改变显示范围，不改变或重采样现有控制点。

默认「选点／空白处框选」：拖动控制点修改值，点击空白定位；在空白处拖框选中多个点，Ctrl 点击可增减选择。「选中视野内所有点」便于处理整段。批量调整支持按比例、整体加减和统一设值，每次操作可一次撤销；总体强度调整保留各点原来的同拍比例。多选后拖动选中点会整体平移数值，保留点间差别。低于合法下限的值会归到 0，同拍平均数下限为 1。

单选时可以精确输入控制点的秒数与数值。双击曲线或「在播放位置加点」可新增插值点，删除操作至少保留一个点。手工新增的细密点会在生成实际查询时刻直接插值读取，不再先被压回两秒网格；自动预测与训练分辨率保持原样。能精确表达控制意图不代表模型会逐个音符硬性服从，还需试听生成结果。

波形、频谱仅用于定位，不作为强制采音标签；素材按音频内容缓存，不运行 MERT、不占用 GPU。未保存的编辑可通过「导出曲线」保存为 JSON 文件。
