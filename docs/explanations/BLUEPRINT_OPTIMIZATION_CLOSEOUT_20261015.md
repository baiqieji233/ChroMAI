## 已实现内容及边界

- `blueprint_cache.py`：独立缓存 Planner 的 CPU 输入和训练目标，不缓存模型预测。身份包含谱面/音频内容、有效 BPM/first、条件、质量标注、曲线、结构与实现指纹；原子落盘，损坏时重建。
- `blueprint_batch.py`、`rational_planner.py`：不同长度的音频与段落输入 padding 后批量计算，以遮罩和逐谱面损失保留目标与梯度。单批梯度与对应单谱面目标之和有回归验证；多谱面一次更新与逐谱面多次优化器更新不具有相同优化轨迹。
- `blueprint_prefetch.py`：线程并行准备，按原序交付，有界队列、异常传播及关闭处理；同音频源的准备由锁保护。训练日志暴露批大小、线程、缓存统计、数据等待与计算时间。
- WebUI：主训练页面提供“全曲规划批大小”“规划准备线程”“规划预取谱面数”，经原 API 转换为 CLI 参数。新 v2 从头训练/finetune 的自动规划批大小为 4；resume 继承已保存批大小，未记录时为 1。旧模型生成合同未改。
