## 主要根因和修复

### 1. 运动学查询重复扫描完整历史

`stream/symmetry.py::kinematic_rows` 对每个查询，都会遍历所有已经提交的轨迹，求最大持续时长，再用它判断需要回看的时间范围。一批有多个历史和音频查询，相同轨迹会被重复扫描很多遍。复杂度为 O(查询数 × 历史事件数)，且主要是 Python 循环。

这种工作虽由数据准备线程预取，也会争用 Python GIL，拖慢主线程提交 CUDA 工作；因此“等数据很短”不能排除数据侧对 GPU 的间接影响。

现在每次调用先构造**持续时长的前缀最大值**，每个查询只读取其已提交事件数对应的值。不会读取未来事件的时长，不缩短历史，不丢弃较早发起但仍在途的长 Slide；被遮罩的轨迹仍然保持遮罩。已有输入/标签和缓存身份不变。

### 2. 档案 token 的重复 Python 整理

`collate_stream` 原来逐事件、逐 token 扩展 owner、位置和长度倒数。现在使用 NumPy 的 repeat/cumsum/向量运算，保留原来的事件顺序、相对字符位置和逆长度，再构造相同 dtype 的 CPU 张量。随机遮罩和 RNG 调用顺序不变。

### 3. 标量指标逐项相加

新的 `MetricAccumulator` 按 dtype 分组累加多个标量，减少每批几十次单独相加的调度。整数计数保持整数；loss 与准确率原有聚合和报告方式不变。

## 真实流水线对照

用同一进程、同一配置和冻结源码快照对照：384 维、6 层、FFN 1536、BF16、batch 8、梯度累积 4、融合 AdamW、cuDNN、4 个数据准备线程、预取 2。取实际训练集前 8 张可用谱面的 8 个代表计算块；各侧短测 24 batch。基线来自修改前备份，未重置或改写用户权重。

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| CPU 批次准备中位时间 | 147.14 ms | 86.00 ms |
| 24 batch 流水线墙钟 | 6.122 s | 4.478 s |

吞吐提升约 **36.7%**，包含预取、GPU 传输、全部前后向、优化器与梯度累积。基线与修改后的对照批次**所有张量逐项完全相同**（rtol=atol=0），包括被遮罩的历史、运动学、档案位置、标签和质量权重。

这是固定的真实批次短对照，不是完整训练轮次，不能据此保证整轮恰好同比提速，也不能保证任务管理器占用到 100%。不同歌曲历史长度、缓存状态和 CPU/GPU 调度仍会影响速度。

## CUDA Graph 的处理和训练结果风险

实现了可选的 `stream/training_graph.py`，仅捕获稠密编码器、解码器，保留其他输入组织、监督与优化器为实时执行。图不写入 checkpoint，也不改变模型参数名称或形状。

实际测量不支持把它默认当作本机速度修复：

- 固定真实 batch 前后向＋优化器短测，普通执行中位约 142.73 ms，图执行约 158.39 ms；合成输入也没有稳定提速。因此 **auto 当前保持普通执行**，显式 `cuda_graph` 才捕获。
- WebUI 新增 **“训练执行方式”**、**“CUDA Graph 额外显存预算（GiB）”**；默认自动、2 GiB，预算 0 关闭图缓存。每个编码器/解码器各最多一种形状，不随曲目无限建立缓存。不同 batch/形状/精度、捕获不支持或预算不足时使用普通路径，不裁剪真实输入。
- 只填充尾部 masked memory 或因果序列尾部，不移动已有位置。图捕获在预取线程启动之前执行，避免全局捕获期间其他线程分配锁页内存。捕获继承实际 AMP 状态并恢复 RNG，不借捕获改变真实训练随机数。
- 集中测试发现了图静态梯度与 `.grad` 存储别名会破坏累积的问题，已修复：回放前保证参数有独立的梯度缓冲区；已有未完成累积不清空；优化器更新后可复用缓冲区。输出正确并不足以证明这条路径训练正确，因此增加了跨多批次、跨优化器更新的检查。
- FP32 与 BF16 的输出、输入梯度、参数梯度、两批累积和 AdamW 更新均有对照；dropout 回放会变化，未冻结成一个遮罩。**显式开启图仍可能改变随机数排列及浮点舍入，不能承诺训练结果逐位复现。**默认普通执行的等价 CPU 优化没有这项变化。
- 初版图短测的 `peak_allocated` 计数较低，但不能推断专用显存峰值同比降低；图私有池还会保留 workspace。最终额外预算同时考虑 allocated 和 reserved 的增长，避免仅按活跃张量低估图缓存。

为了保护训练效果，本轮没有修改 loss、学习率、样本采样概率、dropout 概率、有效 batch、音频节点数、历史长度或谱面表示；未以提高利用率为由加大模型或取消质量目标。
