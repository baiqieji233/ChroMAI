## 精确节奏几何的工作方式

音符时间始终是 `Fraction`。波形只提供音频证据；其原始采样点和邻域测量不是允许输出的拍位列表。新数值特征在进入神经网络时转换为浮点坐标/相位，输出仍是 canonical Fraction token。

解码状态机只有消费到完整位置及 `<note>` 后才暴露该事件坐标；数字前缀和 AT/EOS 判断看不到未来位置。完整前向和逐 token KV 解码使用相同因果状态，回溯后按保留前缀恢复。位置搜索也遵守同一规则。

新增投影采用中性初始化，迁移时保留已有权重；它们需要训练后才能产生学习效果。不能把加入模块等同于旧 checkpoint 已学会节奏。当前布局模型仍主要以字符 CE 训练，辅助数值损失不直接替模型选拍位。

没有 `{8}/{12}/{16}/{24}/{32}` 白名单，也没有输出拍位向固定网格吸附。实现仍有有限资源上限：段内相对 Fraction 分母 4096、位置字符预算、模型 token 容量、事件预算等。相邻间隔或最终编译的 Simai `{分音}` 分母可能更大；不同事件有理数差和编译拆分可产生大分母。

因此，`{5336}`、`{1334}` 等不是本轮应通过文本替换掩盖的问题。它们可能来自未收敛的数值 token 选择、已有错误输入合同或事件间隔组合；本轮提供正确输入和监督、消除资源截断伪休止，并保留日志分辨这些原因。

## 尚未证明是 bug 的质量风险

1. 训练使用作者历史/曲线，生成使用自己的历史与预测曲线，存在分布差异。低 teacher-forced CE 不保证自由生成配置流畅或采音正确。
2. 主要 CE 按字符平均，复杂配置与多位数字占更多目标；数值辅助并不等于按音乐事件评价。没有证据前不再擅自替换主目标。
3. EOS 过早结束仍可能来自模型；`过早结束抑制` 是可选采样偏置，过大又会过密。预算触顶已与主动 EOS 分开记录。
4. 段落分割在不规则音频节点上使用节点均值，密集瞬态可能被赋予更多权重。这是待控样本比较的假设，本轮不以未经验证的算法替换它。
5. 全曲节点预算仍会优先保留强瞬态，弱声部细节可能不足；长歌超预算修复不证明声部采音已经准确。
6. 段落重复发现是音频相似性推断，可能漏关联；它不是已知副歌标签，也不保证多段写法一定呼应。
7. 同尺寸/同 mtime 的极端音频原地替换仍可能绕过波形 LRU 的重新校验；正常文件变更会使来源身份失效。未发现当前任务触发证据。
8. 无理检测和语法通过只说明局部安全/可解析，不能证明配置有趣、手感合理或难度曲线恰当；实际效果仍待用户与专业谱师测试。
