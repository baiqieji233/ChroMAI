# 谱面准备的磁盘缓存索引

日期：2026-10-13。适用于 `song_form_v1`。

## 使用方式

缓存自动启用，无须修改训练参数。首次准备会建立索引；后续启动训练、resume 或 finetune 时，未变化的谱面直接加载准备结果。

位置：当前 `--cache-dir` 下的 `song_form_prepare/v1/`。当前 full 训练集通常为：

`webui_workspace/datasets/full训练集/cache/song_form_prepare/v1/`

WebUI 的音频/样本缓存上限控制进程内存，不会关闭这个磁盘索引。缓存将在下次启动训练时自动生效，刷新页面可看到新增说明与任务显示；本轮未恢复正式训练。

## 缓存内容与失效条件

每张谱面的 JSON 索引配合压缩 NPZ 保存：精确拍位与音符、音乐分段、相似段落描述与关联、训练条件、强度曲线、解析后的长音状态、草稿/修订样本索引、token 目标和过滤审计。

索引包含谱面与音频的内容哈希、难度槽位、定数、匹配的质量标注、`music_structure.json`、拍号、分段时长、token 上限、是否生成修订任务、处理代码及相关依赖版本。变化后重建对应项，不以文件路径相同作为继续复用的依据。

调整无关谱面的质量标注不会使其他谱面的索引全部失效。随机种子和上下文记忆预算不固定在结构索引中，修订遮罩仍在取样时按当前种子生成。

保持原训练输入与 checkpoint 合同；模型形状、词表与生成方式未改变。自定义音频 loader 不启用磁盘结构缓存，避免缓存无法验证的自定义特征。

## 日志

单张谱面日志新增：

- `cache="hit"`：命中磁盘索引，直接复用。
- `cache="rebuilt"`：本次重新构建并尝试保存。
- `cache_reason="miss"`：没有匹配当前输入与参数的索引。
- `cache_reason="invalid"`：索引或数组损坏，已回退重建。
- `cache="disabled"`：使用自定义音频 loader。

阶段统计的 `preparation_cache` 包含命中、未命中、重建、损坏、写入失败数和缓存路径。WebUI 任务摘要同时显示歌曲数、谱面数及缓存状态。

索引与数组有版本/身份/哈希校验；不使用 pickle 加载缓存。多个准备线程或训练进程写入时使用独立临时文件，先发布数组、再原子替换索引。损坏会回退重建；缓存写入失败会提醒并继续训练。缓存可以删除，下次按需重建。
