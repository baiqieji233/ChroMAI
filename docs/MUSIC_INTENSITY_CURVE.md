# 多维音乐张力与可编辑谱面强度曲线

> 2026-10-09 更新：默认模式现为 follow，新增解码时柔性密度反馈、hard 严苛上限与独立休止区间。最新生成操作以 [曲线密度反馈与休止](CURVE_DENSITY_FEEDBACK.md) 为准；重训要求见 [QUALITY_AND_MUSIC_STRUCTURE_V2.md](QUALITY_AND_MUSIC_STRUCTURE_V2.md)。下文保留第一版的严格密度控制记录，普通低曲线不等于精确休止。

这个功能的目标是让“编配撤掉、节奏变稀、张力回落、谱师希望休息”的段落得到更低的谱面密度，即使它的响度仍然不低。它不声称可靠识别人类情绪，也不会把音频响度当成官方谱面难度。

## 两种使用方式

1. **自动强度跟随**：默认选择多维音乐张力，结合节奏起音、频谱活跃度、音色亮度/变化、和声变化和局部段落对比。响度仅是其中一个权重。仍可切换到“仅响度”进行兼容对照。
2. **编辑后的强度曲线**：启用“谱面张力曲线调整”，进入独立曲线页，先针对当前歌曲生成自动曲线，再由谱师拖动或按时间段修改。保存后曲线优先于自动跟随和结尾衰减，避免重复缩放。

自动估计只提供起点：同一音频可以对应不同的创作意图，主歌、间奏、收尾也不应永远由统一响度规则决定。

## 编辑步骤

1. 重启你准备使用的 WebUI 服务，让 Python 后端加载新分析接口；只有刷新页面不会更新正在运行的旧服务。功能有前后端能力检查，旧服务不应静默忽略新参数。不要为此关闭仍在训练的进程。
2. 在生成页导入音频或填写当前目标歌曲的路径。
3. 启用谱面张力曲线调整，进入“强度曲线”独立界面。
4. 点击“生成强度曲线”。分析在 CPU 上独立运行，不使用训练 GPU，也不覆盖训练任务的状态。
5. 查看真实 log-mel dB 频谱背景与绝对时间轴。点击背景定位试听；拖动控制点上下调整强度，时间位置保持不变。
   节点拥挤时使用“时间轴缩放”（1–64 倍），或 Ctrl + 滚轮以鼠标位置缩放；放大后用“浏览时间”滑条平移。“查看全曲”恢复完整视图，频谱、控制点和试听定位使用同一绝对时间范围。
   选择“框选多个点”或按住 Shift 拖动框选，Ctrl 可追加选择。拖动任意已选点可整体上下移动，也可点击整体提高/降低 0.05，或把选中点统一设为某个数值。整体移动保留所选点的高低差，触及 0/1 时整组停止；“统一设为”会把选中点设成相同值。支持放大选区、取消选择与撤销。
6. 也可填写开始秒数、结束秒数、目标强度和边界混合时长，对整段作收束。支持撤销与恢复自动曲线。
7. 点击“保存并返回生成页”，再生成谱面。没保存、换歌或音频内容改变时，不允许沿用旧曲线。

曲线编辑保存时绑定原音频内容 SHA256。分析视图包含频谱，送给生成器的 JSON 只包含曲线和来源信息，避免把大图矩阵当作模型输入。
刷新后会恢复已编辑曲线，并从自动分析文件恢复频谱；若服务重启导致试听任务失效，会提示重新分析。原有编辑曲线仍可用于生成。

## 曲线纵轴的意义

| 强度值 | 含义 |
| --- | --- |
| 0.5 | 当前目标等级/Radar 对应的基准密度意图 |
| 0.3 | 基准密度约 60% 的意图 |
| 0.8 | 基准密度约 160% 的意图 |
| 0 | 休息段；该位置不新增 note head |

倍率 `factor = 2 × intensity` 用于密度条件和 planner 的 count/density 目标。它不是等级换算，0.8 不等于某个官方定数。自动张力的各维权重是可解释的启发式起点，需要靠音乐实测调整。

## 生成时怎样执行

- 保留 checkpoint 的 112 维音频输入、事件词表和窗口布局。已有模型不需要为此从头训练。
- 把曲线按绝对时间与 tempo map 对齐，计算每窗密度和 planner 目标。不会通过伪造 BPM 或改变音符时间压低密度。
- 对超出局部密度目标的输出采用整事件单元的上限控制，保持同一格的和弦/音符文本完整。上下文使用控制后的输出。
- 对低于目标的输出只记录缺口，不在歌曲里盲目补 note。
- 曲线为 0 的段落删除该位置的新 note head，但不会自动缩短在之前开始的 Hold/Slide 尾端。复杂动作和人体可玩性仍需人工检查。
- 质量报告记录目标/实际局部密度、裁减与不足。曲线模式的候选排序参考曲线，而不会用“更像响度”奖励违反谱师意图的输出。

局部密度上限能限制输出过密，但不能保证低密度段落的配置难度一定低：少量复杂 Slide、长 Hold 或大幅度移动仍可能困难。这一版重点交付音乐起伏、可编辑意图和实际密度控制，不把它伪装为完整的手部动作难度估计器。

## 测试建议

固定 checkpoint、歌曲、BPM、first、seed 和其余参数，先比较自动多维跟随与旧响度模式，再比较同一条自动曲线和你编辑后的曲线。每份谱面使用独立输出路径。

关注仍然响的回落段能否收束、段落衔接是否自然、Slide/Touch 比例是否退化以及活动段是否出现意外长空白。音量与音符密度相关性下降不必然表示失败，因为你可能刻意让一段强声音乐休息。

当前训练端仍沿用旧强度条件语义；本次新增的是生成端控制与编辑流程。若现有权重对 planner/条件的响应不充分，报告中的裁减数量会揭示这种情况，后续才考虑在明确的新合同下微调局部规划能力。

自动跟随复用已有 EventAudio 缓存中的节奏、音色和结构代理；独立曲线分析直接读取原音频并产生真实 dB 频谱。两条路径使用相近的多维思路，但特征归一化和采样不同，数值不保证完全一致。需要固定可复现的创作意图时，以保存的曲线为准。
