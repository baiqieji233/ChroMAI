## 难度标签从哪里来

maidata 的 `&lv_x` 经预处理存入 manifest 的 `level_raw` / `level`。事件训练读取该标签，以 `level / 15` 放入 16 维条件向量的第一维；其他 15 维为原谱统计与音频贴合特征。普通条件遮罩与 CFG null 分支保留等级，遮罩其余控制。

精确小数标签按原值读取；`13+` 按项目规则转为 13.7，`14+` 转为 14.7。这只是显示等级到数字的简化规则，无法恢复真实官方定数。缺失或不可解析等级会跳过并记录原因，不会根据音符量自动猜定数。

模型学习「这首音乐 + 这个等级/风格 → 原谱事件」，而非先计算谱面定数再生成。新 music_structure_v2 planner 另有原谱窗口监督：数量、密度、和弦、Slide、Touch、Hold、起音位置、主要配置与相对负荷。负荷约为 `NPS × (1 + 0.35×和弦比例 + 0.2×Slide比例 + 0.1×Hold比例 + 0.15×连打比例 + 0.15×大跳比例)`，再相对全谱平均归一化到以 0.5 为基准的曲线。它也不是官方定数。

quality.json 的 `control.actual.level` 沿用请求的等级，不是评估出来的等级；`level_estimated=false` 明确标记没有定数估计。

## 强度控制对应关系

| WebUI 名称 | 含义与生效条件 |
|---|---|
| 启用谱面张力曲线 | 使用当前歌曲已保存的编辑曲线；指导强度大于零时优先于自动跟随和结尾衰减 |
| 强度跟随（逐窗口） | 开启额外自动参考；关闭不能关闭模型内部 planner |
| 强度跟随模式 | auto 在 music_structure_v2 使用模型规划，旧模型使用多维音频；model 只支持新规划器；multifeature 用多维音频，loudness 只用响度 |
| 强度曲线指导强度 | 0 旁路人工控制，恢复自动设置；1 使用完整目标；不是最终音符数量比例 |
| 强度跟随幅度 | 限制音频自动倍率和 soft 曲线倍率；不限制 model 自然预测、strict 或结尾衰减 |
| 强度曲线模式：soft | 软指导计划/条件，不因曲线事后删音符 |
| 强度曲线模式：strict | 计划指导加约 2 秒区间密度上限，含 15% 容差；删完整起音单元，不补音符，不是精确定数控制 |
| 结尾衰减 | 末尾窗口逐步降低密度条件的人工规则；可与自动跟随相乘；有效人工曲线会覆盖它 |

曲线值 `c` 的原始倍率为 `2c`。soft 先限制到 `[1-span, 1+span]`，再按指导强度 `s` 混合：`effective = 1 + s × (limited_factor - 1)`。默认 span=0.5、s=0.65 时，曲线 0.2 / 0.5 / 0.8 对应 0.675 / 1 / 1.325 倍密度目标。继续把高段从 0.8 拉到 1，在此 soft 范围内不会再加大目标。planner 以相同强度向范围限制后的目标混合；它的自然预测不一定等于全局基准，所以最终事件数不能用上述倍率精确推算。

仅 strict + 指导强度 1 + 曲线值 0 表示该段不允许新起音；已经开始的 Hold / Slide 可跨入该段。

「增强强弱对比」对当前整首曲线执行 `clip(0.5 + 1.25 × (c - 0.5), 0, 1)`。例如 0.3 → 0.25，0.7 → 0.75，基准 0.5 不变。时间不动，原有 0 保持为 0；与框选和视口无关。支持连续点击、撤销、保存、刷新后恢复；不保证平均难度不变。

建议先固定种子，使用随机采样、Temperature 0.65、Top-p 0.9、guidance scale 1、soft、曲线指导强度 0.65。先调全曲等级/密度，再调风格，最后编辑局部曲线。窗口截断才增加 token 预算；温度和 token 上限都不是难度旋钮。语法测试不能证明实际可玩性。
