# song_form_v1 多数据集选择与入口修复

日期：2026-10-13。

## 问题与原因

点击“应用勾选的数据集”虽然能产生联合 manifest，但 song_form 前端训练请求仍检查原始勾选列表。一旦勾选超过一份数据集，它便在发送请求前抛出“song_form_v1 一次训练需要一份已合并 manifest”。因此没有创建训练任务，也没有训练日志。

后端 `start_form_task` 已支持通过 `_prepare_training_sources` 合并 `manifests`；缺失的是前端传递这些来源。另一个操作问题是应用按钮处于数据集卡片区域下方，打开谱面目录后随整个卡片区域隐藏。

## 修改

- song_form 训练请求携带全部勾选的 `manifests` 和 `dataset_paths`，交给已有后端合并后启动训练。无需先手动应用。
- 将“启用质量加权训练”的当前值明确传入 song_form 请求，避免后端默认值覆盖未勾选状态。
- 在“训练模型 → 选择训练素材”增加应用按钮；素材页按钮移动到顶部，浏览谱面目录时仍可见。
- 单选与多选统一调用合并接口，验证清单合同，并显示进行中、完成、失败状态。
- 两个应用按钮共享进行中状态，防止重复请求。应用期间若来源或模型族变化，旧响应不能显示为当前选择的成功结果。
- 联合清单保持在有效训练清单中，不覆盖当前原始目录的预处理输出路径。

## 使用方法

1. 用 Ctrl+F5 刷新主工作台。
2. 在训练素材中勾选已预处理的数据集。
3. 可直接开始训练；也可在训练页“选择训练素材”中点击“应用勾选的数据集”，查看清单准备结果。
4. “检查所选训练来源”用于确认可用谱面数量及过滤原因。尚未预处理的来源仍须先完成预处理。
