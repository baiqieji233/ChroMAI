# 生成后直接预览谱面

日期：2026-11-05。本轮只增加主界面的结果预览，没有修改模型、训练参数、检查点或导出的谱面。

当前部署状态：代码、播放器安装和临时端口的浏览器验收已完成；7862 仍运行旧后台，需停止旧进程后启动新版才能使用新接口。自动审批拒绝了智能体结束该进程的操作，仅返回 `blocked by policy`，未提供更具体原因。原后台没有被停止，临时验收服务已清理。

## 如何使用

1. 进入原来的 **生成谱面** 页，按原流程生成。
2. 页面最上方的 **谱面预览** 状态栏会更新为本次结果。它默认收起，约 47 像素高，不会把参数推到很远。
3. 展开后点击播放器内的 **播放**。支持暂停、拖动时间轴、重播、全屏；播放器的 **设置** 中可以调整流速、皮肤和预览模式。

展开后的播放器宽度最多 440 像素。桌面上把文件信息和操作放在播放器右边，窄屏自动上下排列。需要看清细节时用全屏，收起预览则销毁播放器并释放资源。播放器默认暂停，帧率上限为 30，初始渲染分辨率为 1280×720。

右侧任务结果新增 **预览这次生成** 按钮。它会定位到上方预览区。只要历史任务记录和原始文件仍在，刷新页面或重启 WebUI 后，也能恢复最近一次成功生成的预览。

若同一次任务有多个可用谱面，可以从 **当前谱面** 下拉框切换。文件名带 `.repaired` 的版本单独标明“修正版”；默认展示生成文件，不把不同版本悄悄混在一起。

## 首次安装与离线使用

播放器采用 [MiaView_Web](https://github.com/Team-MiaCode/MiaView_Web) 的公开 SDK 与原生 WebAssembly 构建，不是另写一套近似的谱面动画。

本机已安装完成。换一台电脑时，如果提示缺少播放器，点击 **下载预览播放器**：

- 首次约下载 35 MB，安装后的本地资源约 81 MiB。
- 只下载播放器，不向上游上传谱面、音频或播放诊断。
- 下载在后台进行，不阻塞主界面，也不加载模型或占用训练进程。
- 安装完成后可以离线播放；无需安装 Node.js、Qt 或编译器。

资源保存在 `webui_workspace/preview_runtime/miaview/`，属于本机运行缓存，不提交到 Git。需要迁移离线环境时，可以完整复制这个目录，保留 `current.json` 与 `releases/` 的结构。

也可以在项目根目录手动安装：

```powershell
.\.scratch\python312_runtime\Scripts\python.exe -m maichart.webui.preview_assets
```

运行资源保留了上游的 `LICENSE`、`LICENSE_SCOPE.md` 和 `THIRD_PARTY_NOTICES.md`，预览区提供“许可说明”链接。项目自身的 MIT 许可不覆盖上游的全部素材或运行库；相应范围以上游说明为准。

## 如何避免播错文件

- 谱面和音频按**生成任务**绑定，优先读取该任务实际执行的命令参数。
- 修改当前音频输入框、BPM 或首拍值，不会改变之前结果的预览内容。
- 预览直接读取导出的 maidata，沿用其中的 BPM、变速和首拍设置，不重新测量或改写。
- 缺少原音频时仍可静音看谱；不会自动配上另一首歌。
- 旧的共用输出文件如果已被覆盖，不再把它当成旧任务结果。旧任务留下的修正版也不能混入本次预览。
- 快速切换任务时，较早返回的请求不能覆盖后选的结果；重复刷新任务状态也不会重新加载正在播放的谱面。

媒体通过只读资源地址传给播放器；没有新增任意路径下载接口。音频和 WASM 采用分段流式读取，支持浏览器的 Range / HEAD 请求。WASM 和 ES module 使用正确的 MIME 类型。

## 给维护人员的接线位置

| 部分 | 文件 / 入口 | 职责 |
| --- | --- | --- |
| 主界面 | `static/index.html`、`static/workspace.css` | 生成区顶部的折叠预览和紧凑布局 |
| 播放控制 | `static/chart_preview.js` | 一个播放器实例、按需加载、任务切换和资源释放 |
| 生成完成通知 | `static/app.js` 的 `renderTaskResults` | 提供预览按钮，把完成任务交给播放器 |
| 结果与媒体 | `webui/chart_preview.py` | 读取本次导出和对应音频、检查旧文件是否被覆盖、流式响应 |
| 播放器安装 | `webui/preview_assets.py` | 下载完整 SDK / renderer、校验文件、完成后切换版本 |
| HTTP 路由 | `webui/server.py` | `/api/preview/status`、`latest`、`task`、`resource`、`install` 和 `/miaview/…` |

预览区的文件选择不保存成全局生成参数，避免把某次任务的版本选择带到下一首歌。没有新增独立的 Composer 页面，也没有改变生成请求的模型参数。

播放器更新使用新目录暂存，按上游清单校验大小与 SHA256；SDK 和 renderer 成套获取。所有资源验证完成后才切换版本指针，下载失败不会替换已能工作的版本。旧版本目录保留，正在打开的播放器不会被半成品覆盖。

## 验证与边界

- 相关 WebUI / API / 预览 Python 回归共 178 项通过；现有界面 JavaScript 测试 255 项通过。
- 用实际生成的约 137 秒、882 个音符的谱面加载了完整 MiaView WASM 播放器；检查了默认暂停、播放、暂停、跳转至 20 秒、流速设置和全屏。
- 在桌面与 390 像素宽的手机视口检查布局：默认预览栏高度 47 像素；手机预览区没有横向溢出。
- 检查了同一任务刷新不重建播放器、收起后 iframe 释放，以及通过延迟请求模拟的任务切换顺序。
- 桌面浏览器在阻断外网请求的情况下完成加载和播放。浏览器无页面脚本错误。
