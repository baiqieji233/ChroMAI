# Composer 结构查询热路径性能修复

日期：2026-10-27。

## 修改

1. `backend_identity` 在进程内固定分析器身份。热查询不再查包、stat 权重或解析权重路径。运行/续训/生成入口使用 `refresh=True` 校验实际版本；返回字典副本，避免调用者修改共享缓存。
2. `structure._bank` 增加最多 128 项的对象查询缓存。命中后直接读取已建立的结构库，不再计算 JSON、SHA256 或规范化缓存路径。键包含音频对象、first、完整 tempo 值、缓存目录、后端/schema 和显式刷新代号。
3. 新增 `structure_features_and_transition`。训练、恢复采样与生成把当前候选和上一已提交事件合成一次查询，随后计算差值。
4. 不改变特征 schema、权重、损失、采样策略或训练数据划分。缓存代表运行中的不可变源；修改源或后端时须在运行边界刷新/清理。
