# 局部采音对齐：实现与验证边界

当前增加的是可选能力，尚未完成全量训练和质量验收。原 v3 全量训练与既定微调仍作为对照继续执行。

## 为什么需要它

现有 v3 planner 为每个窗口给出强弱、密度、类型比例和一个短间隔比例。最后一项只统计不超过 `33/128` 拍的间隔，不能表达具体哪些时刻该落音，也覆盖不到所有半拍和三分之一拍的采音变化。

实际诊断使用 epoch 7、128 个固定验证窗口：在给定正确历史 token 的条件下，打乱局部声学帧后整体 token accuracy 仅从 0.743866 变为 0.743061。全曲参数对照也表明，提高细碎偏好能增加短间隔音符，却同时明显增加总 note 数；这不足以证明采到了正确的音乐位置。上述证据支持加强局部时序监督，不能据此断言模型完全不使用音频。

## 学习内容

`chart_onsets_v1` 在音频 encoder 的 local memory 上增加一个小型逐帧预测头。目标来自谱师实际写出的音符起点；同拍和弦只算一个时间位置。它学习的是音乐、定数和谱师选择共同对应的落音位置，不是把每个声学峰都写成音符，也不指定必须使用三连音。

训练标签使用真实 tempo map 和 `audio_first`，与音频张量共用采样网格。高斯软标签宽度为 20 ms；只在当前窗口、文件有效时间和有正向质量权重的区域监督。margin 提供上下文，padding 和被排除的区域不承担这项损失。

旧 v3 的 planner 维度与短间隔目标保持原语义。新头单独记录 `onset_profile` 与目标合同，可以通过显式 finetune 初始化；旧 checkpoint 生成默认不启用它。

## 生成侧

`local_onset_bias_strength` 范围 0–1，默认 0。启用时，从新头读取局部起点分数，把合法 `AT:` 候选经完整 tempo map 换算到实际秒数，再进行软偏置。上下文偏移和 encoder 下采样都会参与时间对齐，最终拍位仍是原 EventIR 的精确 Fraction。

偏置只重新分配合法位置之间的概率；在 top-p 截断前保留位置组的总概率质量，不直接修改音符字符或 EOS。已有休止、合法拍位和密度屏蔽仍然有效，不会被重新打开。top-p 与后续历史变化仍可能影响总密度，因此不能声称强度旋钮完全不影响 note 数。CFG 的条件和 null 分支也共同作用于起点预测。

建议正式对照使用 0、0.3、0.6，保持模型、音频、种子、定数与其余采样参数一致。没有实际训练过起点头的 checkpoint 会拒绝非零强度，避免显示可用但没有对应能力。

## 必须完成的验证

- core、margin、负偏移、变 BPM、同拍去重、质量屏蔽及混合长度池化的时间对齐。
- 从旧 v3 新建头的 finetune、带头模型 resume、旧模型加载和零指导行为。
- 完整训练后起点定位、校准、空白窗口、半拍及更细间隔、配置类型、重复配置、密度和边界对照。
- 可玩性静态报告与人工审阅。该头不解决全部 Slide 判定和双手调度问题，不能据此宣称整谱可玩。
